# 모바일 조작 구현 계획과 적용

목표: 별도 앱 설치 없이 모바일 브라우저에서 이동·시점·양손 거미줄을 동시에 조작한다.

- 왼쪽 고정 스틱: 이동, 외곽 85% 이상 질주. 중앙 16% 데드존.
- 오른쪽 화면 드래그: 시점. 거미줄 버튼을 누른 채 드래그해도 시점 조절.
- 오른쪽 기본 6버튼: 왼손 웹, 오른손 웹, 점프, 웹 집, 벽 이동, 더보기.
- 더보기: 전투/웹 모드, 방어, 회피, 강공격, 묘기, 시점, 시점 정렬.
- 상단 지도/메뉴. 작은 미니맵과 간략한 상태 표시. 세로·가로 화면, 화면 안전 영역 대응.
- 터치 장치 자동 감지. 데스크톱 키보드·마우스·게임패드와 입력 소유권 분리.
- 거미줄은 화면 중앙 조준점 사용, 터치는 항상 누르는 동안 유지. 기존 클릭 토글 설정과 분리.
- 포인터별 소유권과 캡처. 손가락 이탈/취소, 화면 회전, 앱 전환, 메뉴/지도 진입 시 입력 해제.
- 키 재설정은 기존 바인딩을 따름. 스틱 질주는 별도 터치 상태로 관리.

구현: `src/TouchControls.js`, `src/main.js`, `src/style.css`, `index.html`.

검증: 스틱 방향/데드존/질주, 동시 양손 및 시점, 포인터 취소/일시정지 후 해제,
터치와 키보드/게임패드 분리, 바인딩, 세로·가로 화면 배치, 빌드와 기존 입력 수명주기 테스트.
실제 iOS/Android 기기별 성능은 해당 하드웨어에서 추가 확인이 필요하다.
