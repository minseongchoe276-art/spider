# 홍콩 맵 그래픽 수리 계획과 진행 상태

대상은 약 4.8km × 4.8km 플레이 범위의 사진측량 타일과 별도로 제작된 보강 자산이다. 사진측량 원본에서 잃은 건물·수목 형상은 해상도 설정이나 셰이더로 복구할 수 없으므로, 전체 수리 완료 판정에는 위치별 대체 모델과 충돌 검수가 필요하다.

1. **기준 조사:** 실제 품질 설정으로 격자별 화면과 타일 상태를 기록한다. 49개 지점의 재조사는 수행했지만 모든 캡처에서 요청이 진행 중이었고 각 지점 한 시점만 촬영했으므로 개별 요소의 합격 판정이 아니다. 정착 전후, 지상·옥상·해안, 사방과 낮·밤을 추가 조사한다.
2. **공통 렌더링:** 잘못된 삼각형과 비정상 좌표가 경계·충돌에 미치는 영향을 수정하고, 저지대 도로·부두의 물색 오분류를 제거한다. 외벽 보강은 실제 검토된 삼각형 범위로 제한한다. 각 수정은 합성 오류 사례와 WebGL로 검증한다.
3. **시작 구역:** 실제 이동 시점의 도로, 보도, 테라스, 벽, 보행교, 식생의 원본 결함을 좌표별로 기록하고 대체 모델을 제작한다. 렌더·충돌의 위치와 로딩 실패 시 복구를 함께 확인한다.
4. **전 지역 확장:** 도심의 건물·지붕·도로, 산지와 수목, 해안과 수면을 구역별로 조사해 모델과 지리 경계를 확보한다. 원본을 임의의 넓은 평면으로 덮지 않고 각 교체의 충돌과 경계, 접근 경로를 검증한다.
5. **스트리밍과 성능:** 상세 타일의 정착 시간, 네트워크 실패·복구, 캐시 압력, 이동 중 지지면과 프레임 시간을 실제 장치에서 확인한다. 저사양 기기의 메모리와 성능을 확인하지 않은 채 상세도와 캐시를 일괄 확대하지 않는다.
6. **출시:** 지상 이동·점프·벽 타기·와이어·차량, 날씨와 미니맵을 포함해 구역별 전후 화면을 검수하고 빌드 및 관련 테스트를 통과한다. 사용되지 않는 조깅 원본을 배포본에서만 제외해 전체 자산 250MB 제한은 통과했으며, 원본과 모든 현재 모션 대체 파일은 유지한다.

현재 전 지역 대체 자산 제작과 모든 각도의 시각 검수는 미완료다. 격자 조사 결과와 자동 검사는 전체 요소 수리 완료의 근거가 아니다.
