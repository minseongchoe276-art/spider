# Weapon animation sources

The rifle idle (`Rifle Aim Idle.fbx`), rifle firing (`Rifle Firing.fbx`), and melee swing (`Weapon Slash.fbx`) are copied from the local `SoldierThirdPersonThreeJS/public/animations` project. Its README credits the animations to Mixamo. They are retargeted and compiled by `scripts/build-motions.mjs`; the melee swing is shared by the baseball bat and metal pipe. The rifle pose also uses runtime hand and weapon alignment.
