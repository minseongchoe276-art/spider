# 민첩한 전투 안무 재구성

2026-10-11. 이전 수정은 가드를 유지하는 정적인 복싱 동작에 머물렀다. 이번에는 두 번의 주먹 공격과 회전차기를 연결하고 강공격을 앞차기로 변경했다.

- 좌클릭 3타: 발을 디디는 잽 → 뒤 발과 골반을 회전시키는 스트레이트 → 몸 전체를 회전하는 돌려차기.
- E 지상 강공격: 준비 자세에서 무릎을 들어 올리고 몸 높이까지 뻗는 앞차기. E 공중 내려찍기는 유지한다.
- 더 낮은 기본 스탠스, 공격별 골반 이동·회전, 차는 발의 궤적과 팔의 균형 동작을 구성했다.
- 공통 fighting stance의 골반 위치를 사용한다. 각 공격의 원본 마지막 프레임을 골반 기준으로 삼던 문제 때문에 발차기의 지지발이 뜨던 결함도 수정했다.
- 차는 발은 지면 접촉 메타데이터에서 제외하여 런타임 IK가 바닥으로 끌어내리지 않는다. 반대 발은 지지발로 사용한다.
- 회전차기 0.85초, 앞차기 0.9초에 맞춰 실제 타격 판정 구간도 조정했다. 기존 입력, 피해량, 거미줄 모드 분리는 유지한다.
- 1인칭 팔 표시가 발차기를 주먹질로 표시하지 않도록 조정했다. 1인칭용 발 모델은 추가하지 않았다.

검증: npm test 및 npm run build 통과. 실제 리그 30/60/144 FPS의 42개 전투 경우, 주먹의 전방 궤적·지지발 안정성·가드 복귀, 발차기의 높이·방향·지지발·IK 접촉 해제·회수 검사 통과. 전체 37개 모션의 111개 타임라인, 15,320프레임 검사도 통과했다. 기존 홍콩·거미줄 검사 통과.

전투 검토 화면에서 중간 회전, 타격, 준비·회수 구간을 직접 렌더링하고 실제 속도 및 느린 속도 콤보를 실행했다. 스크린샷과 실행 기록은 같은 디렉터리에 저장한다. 기존 게임 탭에서 이전 번들이 표시되어 최신 빌드로 다시 열었다. 실제 홍콩에서도 jab/cross/hook 전환을 확인했고 위치 X/Z는 (0, 0)으로 유지됐다 (`hong-kong.json`).

이 변경은 현재 뼈대에 직접 구성한 파생 안무다. 상용 게임 원본 애니메이션이나 새로운 모션 캡처를 가져온 것으로 설명하지 않는다. 자세의 안정성 검증과 미적 완성도 판단은 구분한다.
