## 실제로 재현해 수정한 문제

1. **A → B 전환 중 C로 다시 전환**: A의 이전 종료 시각과 B의 새 종료 시각이 달라 가중치 합이 0.9135802804까지 떨어졌다. 남은 약 8.64%에는 기본 바인드 자세가 섞일 수 있었다. 전환 도중 다시 바뀌면 현재 혼합 자세를 보존하고 하나의 동일한 전환 시간으로 다음 모션에 연결하도록 수정했다.
2. **전환 중 즉시 전환(duration 0)**: 가장 최근 동작만 정지해 더 오래된 동작이 남았다. 재현 시 가중치 합이 1.7777777910이었으며 목표 모션 이외의 자세가 섞였다. 즉시 전환은 이전에 예약된 모든 동작을 해제하고 목표 모션 하나가 자세를 소유하도록 수정했다.

수정은 `src/Character.js`의 모션 연결에 적용했다. 일반 클립 타이밍, 동작 속도, 공격 판정과 물리는 변경하지 않았다. 수정 전 실패는 `interruptions-before.json`, `hard-cut-before.json`에 보존했다.

## 검수 버전의 고정

작업공간에서 별도로 진행 중인 UI 변경 때문에 최초 통합 실행 도중 소스가 바뀌었다. 이 실행에서 ‘집 이동 중/집 대기’라는 이전 문구를 찾던 검사가 실패했다. 기능은 그대로이고 문구가 ‘당기는 중/당기기 대기’로 바뀐 것을 확인한 뒤, 검사를 현재 문구에 맞춰 갱신했다. 중단한 결과는 `working-tree-partial.json`, 당시 상세 로그는 `full/`에 남겼다.

이후 검수용 복사본을 고정했다. `snapshot.json`은 복사본 경로를 기록하며, 확장된 전체 검사는 그 버전에서 실행한다. 의존성은 작업공간의 `node_modules`를 읽기 전용 용도로 공유한다. 게임 소스·모션·외형·검사 코드·패키지 정의의 실행 전후 해시는 `verified/source-integrity.json`에서 확인한다. 검수 후 현재 작업공간과 비교한 차이도 최종 판정에 명시한다.

## 아직 증명하지 않은 범위

실제 인터넷의 모든 지연·손실·재정렬과 운영 서버, 홍콩 스트리밍 지형 전체, 모든 기기·GPU·브라우저의 실시간 렌더링, 무제한 길이의 입력 순서, 모든 장면의 예술적 자연스러움을 완벽하게 증명하지 않았다. 패킷 검사는 수신 시각을 제어한 모의 검사이며 실제 인터넷 검사가 아니다. 통합 통과는 명시한 수치·상태 행렬에 대한 결과이고 ‘모든 상황에 절대 결함 없음’ 판정은 아니다.
