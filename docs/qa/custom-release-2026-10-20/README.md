- `full-suite.log`: 최초 실행 및 발견된 회귀 기록.
- `remaining-suite.log`: release audit 수정 후 통과 및 DOM 대역 누락 발견 기록.
- `remaining-suite-2.log`: DOM 대역 수정 후 나머지 26단계 모두 통과.
