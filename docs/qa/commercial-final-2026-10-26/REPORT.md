## 실제 브라우저 검증

Chrome의 실제 화면과 읽기 전용 DOM 사각형을 확인했다. 원본 숫자·단위의 영역, 미니맵·메뉴·스틱·와이어·점프·더보기·안내/목표 패널의 교차와 화면 밖 이탈을 검사했다. 모달이 의도적으로 덮는 화면은 HUD 겹침으로 분류하지 않았다.

<!-- UI_RESULTS -->

브라우저 크기 변경 및 개발용 touchReview 모드는 실기기 시험이 아니다. 검수 중 다른 작업의 소스 변경으로 개발 페이지가 다시 로드돼, 이후 화면 검사에서는 전용 개발 서버의 파일 감시를 끄고 진행했다. 최종 전체 소스의 동일성은 별도로 전체 검사 전후 해시와 최종 빌드 식별자로 확인한다.

검수 중 발견한 실패 조합도 보존했다. mobile-before-toolbar-fix.json은 수정 전 가로 화면 실패 기록이며 최종 통과 결과가 아니다. 이전 상업 준비 폴더와 full-before-objective-fix는 중간 기록이다.

## 검증 범위와 해석

전체 검사는 실제 물리·리그·로컬 WebSocket·로컬 PostgreSQL을 사용하는 검사와 DOM 대체물·소스 계약 검사를 포함한다. 묶음 수는 실제 사용자 수나 전 상황의 완전 탐색 수가 아니다. 새로 추가된 홍콩 벽·난간·안전 복귀 변경도 최종 작업본에 포함해 검증한다.

빌드는 원본 모션을 다시 생성하지 않고 검증한 컴파일 모션을 재사용했다. 모델·모션을 삭제하거나 품질을 낮춰 수치만 맞추지 않았다. 운영 DB 조회는 읽기 전용이며 운영 배포·권한 확대·비밀값 설정은 수행하지 않았다.

## 상업 배포 전 남은 문제

**로컬 기술 검사 통과와 상업 출시 승인은 구분한다.** 남은 운영 반영, 에셋 증빙, 실제 기기·사람 평가와 보안 진단 해석은 [별도 미완료 보고서](REMAINING.md)에 정리했다.
