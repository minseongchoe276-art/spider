# 모바일 스윙 완성 검수 — 2026-10-25

기본 화면은 이동 스틱, 거미줄, 점프와 더보기로 구성합니다. 한 번 터치해 연결하고 손을 떼어도 유지하며, 재터치하면 놓습니다. 점프는 줄을 놓고 도약합니다. 손 선택은 필요 없으며 발사할 때 손이 교대됩니다. 버튼 위 드래그는 시점 조절로 처리해 잘못 발사하지 않습니다. 전투·보조 와이어·벽 이동 등은 더보기에서 접근합니다.

카메라는 진행 방향을 완만하게 따르며, 수동 드래그와 이후 유예 시간이 우선입니다. 옆/뒤 이동의 기준을 임의로 돌리지 않고, 진자 역전 때 180도 반전하지 않습니다. 벽 때문에 카메라가 모델 안으로 밀리면 로컬 몸체만 가려 시야를 확보하고, 거리가 확보되면 복구합니다. 모바일의 시작 각도는 완만한 0.12rad를 사용하고 데스크톱 지역 미리보기 각도는 유지합니다.

거미줄 보조는 화면 앞쪽의 실제 지형을 최대 10개 광선으로 찾습니다. 사거리, 앞쪽/화면 범위, 높이, 장애물과 스트리밍 지형 준비 상태를 검사합니다. 초록 원은 연결 가능한 지점입니다. 적을 자동 선택하거나 서버 피해 판정을 변경하지 않습니다. 실패·끊김 뒤 숨은 재발사 입력을 계속 유지하지 않습니다.

새 모바일 솔로 진입은 안전한 위치에서 연결 가능한 방향을 찾습니다. 높은 항만 옥상처럼 사용할 지점이 없으면 안전한 거리에서 시작할 수 있습니다. 저장 위치는 옮기지 않고, 온라인 및 스트리밍 도시의 시작 위치에는 적용하지 않습니다. 검사에서 5개 로컬 맵 모두 실제 충돌 보정 카메라로 연결 지점을 확인했습니다.
