## 수정 전후 재현 수치

`before-after.json`은 수정 전 스냅샷을 별도 임시 모듈로 로드해 같은 입력을 비교했다.

- 정지 공격 중 이동 시작: 이동 0m → 약 0.679m. 이동 입력이 공격에 막히는 문제 재현 및 수정.
- 옆 이동 잽의 최소 발목 중심 간격: 약 1.84cm → 13.0cm.
- F + 질주 실제 속도: 수정 전후 약 2.275m/s로 동일. 표시 모션만 run → walk.
- 같은 F+옆 이동 입력의 CPU 모의 갱신 중앙값: 약 7.98ms → 6.94ms. 80프레임 준비 후 60프레임 × 5회 측정. 실행 순서·JIT·환경 영향을 받는 단일 모의 조건이며 GPU FPS나 실기기 8인 성능 보장은 아님.

## 검증

- 288/288 조합 통과: 정지·8방향 × 잽·스트레이트·훅·가드 × 계속 이동·공격 중 이동 시작·정지·반전 × 30/60 FPS.
- 각 공격은 타격 순간만 고정하지 않고 시작부터 종료 후 0.3초까지 실행. 공격 판정 구간에서 주먹이 실제로 뻗는지, 관절 유한성·정규화, 좌우 발 교차, 회복을 검사.
- 실제 GameApp 키·마우스 입력 경로 32조합 통과: WASD·방향키·Shift와 네 동작, F 해제·재입력, 점프 중단, 키 해제.
- 전투 조준 회전·전환·구르기 회복·시점 변경·관절·미끄럼·초기화·거미줄 회귀 등 15개 검증 묶음에서 확인. 최초 온라인 1개 실패는 원인 수정 후 재실행 통과.
- 최종 소스를 고정한 5개 묶음 재실행 5/5 통과, 검사 전후 및 현재 소스 해시 동일.
- 손목·발목 최종 출력 48/48 사례, 13,254프레임 통과. 집중 대상은 combatIdle·jab·cross·heavy·guard.
- 실제 사용 외형의 피부 메시·손목 검사 24조건 통과: 네 동작 × 두 속도 × 전진·옆·후진 대각선. 원본 정점 대비 최대 삼각형 변형은 기존 0.16m 검사 한도 내, 손목은 12.1° 검사 한도 내.
- 8명 × 다른 관찰자 7명 = 원격 리그 56개 검사 통과. 별도로 이동 중 잽·스트레이트·훅·가드의 시계를 24/60/144 FPS에서 검사.
- 빌드 통과. 기존 큰 번들 크기 경고는 남음.

전체 실행 로그는 `validation-final.log`, `validation.json`, 최종 재실행은 `replay-validation.json`, 종합은 `summary.json`에 보존했다. 원격 모션 우선순위를 고친 최종 변경은 네트워크 조건에만 적용되며, 최종 재실행에서 다시 확인했다. 앞선 288개 로컬 행렬을 네트워크 수정 뒤 전부 다시 실행했다고 주장하지 않는다.
