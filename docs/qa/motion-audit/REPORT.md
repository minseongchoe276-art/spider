# 전체 모션 검증 및 드론 제거

검증일: 2026-10-11

## 결과

훈련 드론 생성 코드와 AI, B 키, 게임·검증 화면의 버튼 및 HUD 안내를 제거했다. 실제 게임에서 B를 눌러도 드론이 생성되지 않으며, 콘솔 오류가 없음을 확인했다. 전투 공격·방어·회피·거미줄 모드 전환은 유지한다. 드론이 사라져도 전투 대기 자세를 사용할 수 있게 했다.

검증 대상은 현재 모션 카탈로그의 전체 **37개**다. 이동·정지·회전, 점프·낙하·착지·구르기, 스윙·웹 집·벽 타기, 전투·방어·회피·피격을 포함한다.

## 발견하여 수정한 문제

1. **공중 내려찍기의 시각적 착지가 실제 접촉보다 먼저 진행되는 문제**: 게임 액션 시간과 애니메이션 시간을 동기화했다. 착지 전에는 실제로 62% 구간을 유지하며, 접촉 이후에만 착지 모션으로 전환한다.
2. **전투 대기가 이동 정지 모션을 잘라버리는 문제**: 이동 직후 stop/runStop이 끝난 뒤 전투 대기로 넘어간다.
3. **앞 구르기 및 내려찍기 착지가 공중에 뜨는 문제**: 수직 골반 이동까지 제거하던 변환을 수정했다. 대상 GLB의 부모 뼈가 회전되어 있어 로컬 Y 대신 월드 수직축을 로컬 좌표로 변환해 적용한다. 가로 이동은 계속 물리 시스템이 담당한다.
4. **방어 파생 모션의 변환 결과가 bones 래퍼 객체에 의존하는 문제**: 동일한 실제 골반 뼈를 기준으로 원본 전투 대기 자세를 재사용해, 반복 검사 시에도 같은 하체 결과를 얻는다.
5. **웹 집 검증 카메라가 테스트 건물 내부에 들어가 캐릭터를 가리는 문제**: 해당 검증 시나리오의 카메라를 측면으로 옮겨 자세가 보이게 했다.

## 검사 방법과 증거

- **전체 타임라인**: 37개 × 30/60/144 FPS = **111개 경우, 15,219개 프레임**. 유한한 관절 위치, 정규화된 회전, 팔다리 뼈 길이 보존, 손·발·머리의 급격한 이탈 여부를 검사한다. 끝점 속도 30m/s는 폭주 검출용 상한이며 예술적 자연스러움의 합격 기준을 대체하지 않는다.
- **공중 내려찍기 회귀 검사**: 실제 Character.update를 120프레임 진행해도 착지 전 지정 구간을 벗어나지 않는지 확인한다.
- **골반 수직 이동 회귀 검사**: 구르기와 착지의 골반 높이 변화가 25cm 이상 보존되는지 검사한다.
- **실제 캐릭터 전투 검사**: 14종 × 3 FPS 조건 = 42개 경우. 자세·접지·동일 모션 재시작을 검사한다.
- **전투 동작 검사 10개**: 모드 분리, 콤보, 타격 판정, 방어·회피, 실제 착지, 드론 생성 기능 제거, 정지 모션 보존. 피해 판정은 별도 테스트 대상 객체로 검증한다. 게임에는 새 적을 추가하지 않았다.
- **기존 이동·지형·웹 검사**: 걷기·달리기 발 접촉과 미끄러짐, 벽 접촉, 옥상 진입, 경사·계단, 양손 거미줄, 프레임률 차이, 회복 동작을 포함하는 기존 전체 테스트.
- **렌더링 검토**: 전체 37개 모션의 45% 구간을 각각 촬영해 비교했다. 원본 클립 검토에는 실제 지형 IK 보정이 포함되지 않으므로 발 접지는 별도 런타임 검사와 구분한다. 구르기와 착지 수정 뒤 해당 화면을 다시 촬영했다.
- **12개 실제 전환 시나리오**: 이동, 걷기 정지, 좌우 회전, 낙하 착지, 높은 낙하 구르기, 웹 집, 스윙 해제, 양손 연결, 벽 타기·옥상 진입, 경사 오르기·내리기, 계단. 이동 시나리오는 13초까지 진행해 walk → jog → regularRun → run → runStop → idle → jump → drop → land를 확인했다. 걷기 정지는 6초까지 진행해 walk → stop → idle을 확인했다.
- **게임 화면**: 드론과 B 안내 제거, 전투 대기, 콘솔 오류 없음 확인.

명령: `npm test`, `npm run build`. 전체 테스트와 빌드 통과. 기존 대형 번들 경고는 남아 있다.

## 판단의 범위

검사에서 발견한 결함은 수정했지만, 모든 환경에서 ‘완벽하다’고 보증할 수는 없다. 수치 검사와 렌더링 검토는 자세 붕괴·시간 불일치·접촉 오류를 찾는 증거이며, 모든 카메라 각도에서의 실루엣·취향·실제 적과의 전투 연출을 보증하지 않는다. 피격 모션과 일부 낙하·정지 변형은 보관된 대체 클립이며, 모두가 현재 게임 입력에서 직접 호출되는 것은 아니다.

브라우저 검증은 고정 지형 검증 화면 및 절차 생성 도시에서 진행했다. 홍콩 스트리밍 전체 지역, 모바일·게임패드 및 다른 GPU는 이번 검증 범위에 포함되지 않는다.
