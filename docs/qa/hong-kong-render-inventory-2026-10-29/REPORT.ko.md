# 홍콩 렌더링 구성·결함 조사 — 2026-10-29

현재 화면에는 실제 시각 품질 문제가 있다. 나무·난간·보행교·바닥·외벽을 각각 확인했고, 모델 손상처럼 보이는 원본 형상과 런타임 품질 저하, 부분 보강의 경계를 분리했다. 이번 작업은 조사와 재현 도구 추가이며, 아래 결함을 모두 수정했다는 보고가 아니다.

## 확인 범위

- 지도/동적 환경 10개 진입 모듈에서 시작한 의존성 목록: 37개 모듈. 전역 렌더러·프록시·해상도 조정 경로는 추가로 목록화했다.
- 시작 구역 8방향과 최초 화면에서 관찰된 메시 인스턴스 433개, 텍스처 인스턴스 384개. 이는 서로 다른 물리 건물/나무의 개수가 아니며 LOD/재로딩 인스턴스를 포함한다.
- 각 스캔의 현재 로드된 메시 전체를 검사했다. 지도의 모든 좌표·모든 건물 면을 육안 검수했다는 뜻은 아니다.
- 계획한 지역 격자 49곳 중 2곳만 시도했으며, 낮은 고정 높이의 카메라가 산지 표면 안에 들어간 화면은 렌더링 결함 증거에서 제외했다. 47곳은 미방문이다. 상위 타일의 큰 리소스 때문에 응답 헤더 용량 합계가 조사 예산을 넘었고 광역 순회는 완료하지 않았다. 이 수치는 실제 외부 전송량이 아니라 관측한 Content-Length 합계다.
- 일부 근접 시점에도 다운로드가 진행 중이었다. 그 화면을 최종 정착 LOD 품질의 증거로 쓰지 않았다. 기본적인 뭉개진 수목·재질 경계 문제는 원본/보강 비교 화면에서도 확인된다.

## 오류로 단정하지 않은 항목

- 법선 속성이 없는 GLTF 메시 36개 모두 비조명 또는 정상적인 flat shading 경로로 확인했다. 최초 후보 탐지기의 법선 경고는 오탐이어서 수정했다. 법선이 없다는 이유로 강제 평활화하면 오히려 원본 외형을 바꿀 수 있다.
- 보완 스캔의 NaN 좌표/UV 누락 등 실제 속성 경고는 0개였다. GPU/셰이더 페이지 오류도 수집된 범위에서 0개였다. 시각적 원본 결함이 없다는 뜻은 아니다.
- 타일 요청 124건은 모두 net::ERR_ABORTED였다. 카메라·LOD 전환 때의 취소를 서버 장애/HTTP 실패로 집계하지 않았다.
- 건물/시설물 독립 계층을 사진 계층 위에 중첩하는 예전 구성은 현재 코드에서 이미 꺼져 있다. 현재 보이는 모든 문제를 이 중첩 탓으로 돌릴 수 없다.
- 시작 스캔의 메시별 정리 기록에는 중복 면 29개, 면적 0 삼각형 17개가 있었다. 이 정리는 사진에 뭉쳐 저장된 나무·교량 형상을 복원하지 못한다.

## 작업 순서

1. 원본 형상 문제와 런타임 LOD 문제를 동일 카메라·고정 품질·다운로드 정착 후 다시 비교한다.
2. 플레이어가 접근하는 거리·공원·교량부터 구역별 실제 메시/재질을 복원한다. 원본 수목 전체를 무차별 숨기는 식으로 처리하지 않는다.
3. 외벽/수목 교체 경계를 닫고 시각·충돌·카메라의 정합을 함께 맞춘다.
4. 근거리 품질을 보장하는 스트리밍 정책과 보강 모델 LOD를 적용한다.
5. 동일 카메라의 낮/밤/비, 낮음/균형/높음, 이동 전/후를 각각 확인한 뒤 구역을 완료로 표시한다.
6. 광역 격자는 높이 적응형 조사 카메라와 타일별 진행 기록을 보완한 뒤 재개한다. 현재 미방문 구역을 완료로 표시하지 않는다.
