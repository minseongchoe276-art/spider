# 홍콩 스트리밍 수정 및 검증

검증 기준: `2adb2cf829902c67eaed770efe8b5e36d41fd841`와 이번 작업 변경만 포함한 별도 검증본. 기존 작업 폴더의 다른 미완료 변경은 제외했다.

## 수정

- 재시도: 이용 시간 전체에 누적되는 5회 제한을 제거했다. 연속 실패에는 최대 30초 간격으로 계속 재시도하며, 정상 복구 후 간격을 초기화한다. 같은 실패 묶음이 재시도 시점을 계속 뒤로 미루지 않게 했다.
- 설정: 같은 품질을 다시 적용할 때 적응형 세부 묘사와 캐시 예산을 초기화하지 않는다. 실제 품질 변경은 정상 반영한다.
- 표시 경계: 각 품질의 타일 로딩 거리 안에서 안개가 완전히 덮이도록 했다. 실제 카메라 거리가 더 짧아지면 안개도 그 거리에 맞춘다.
- 추가 성능 보완: 충돌 대기열의 우선순위를 갱신할 때 정적 타일의 모든 정점을 다시 훑지 않고 계산된 경계 상자를 재사용한다.

앞의 세 수정은 기준 커밋에도 포함되어 있다. 이번 커밋은 짧은 카메라 거리 대응, 충돌 경계 상자 재사용, 재현 검사와 실제 플레이 증거를 추가한다.

## 결과

- 회귀 검사: 연속 8회 실패, 재시도 간격 상한, 중복 실패 시 기존 재시도 시점 유지, 복구 이후 별도 실패의 재시도, 설정값 유지 및 실제 품질 전환 통과.
- 실제 서버 오류: 지형 루트 요청에 HTTP 503을 6회 주입했다. 7번째 요청에서 정상 진행되어 약 105.0초에 시작 준비를 마쳤고, 재시도 상태는 `retryAt=0, retries=0`으로 복구했다. 이후 키보드 이동·점프와 착지를 확인했다.
- 별도 검증본 실제 플레이: 접지 상태에서 점프하고 착지를 기다린 후 질주했다. 이동 거리 14.9m, 와이어 이동 22.8m. 카메라 세 방향 회전, 실제 UI로 모션 감소와 낮음/높음/기본 품질 전환을 확인했다.
- 성능값 보존: 모션 감소 설정 조작 전후 `25 → 25`.
- WebGL: 세 품질에서 거리별 픽셀이 점진적으로 안개색에 가까워지고, 로딩 경계 전에는 배경색과 RGB 합산 오차 3 이하로 일치했다.
- 브라우저 예외 및 셰이더 오류: 0건. 의도적으로 주입한 HTTP 오류는 별도다.
- 별도 검증본의 프로덕션 빌드와 충돌·추락 복구 검사를 통과했다.

## 범위와 한계

데스크톱 headless Chrome과 실제 외부 타일로 확인했다. 설정 검사는 압력 제어 갱신만 잠시 멈추고 정상 UI 핸들러를 사용했다. 와이어 목표 조준 및 시작 지점 복귀는 기존 QA API를 사용했다. 외부 타일 수신 중 순간 프레임 하락은 남아 있으며, 이 실행을 성능 벤치마크나 실제 모바일·장시간 전체 맵 검증으로 해석하지 않는다.

검증 초안에서 낙하 중 점프를 요구하던 조건은 접지 후 점프로 수정했다. 카메라·상세도 변경으로 더는 필요하지 않은 특정 세부 타일까지 다시 다운로드하도록 요구하던 조건은 제거했다. 실제 재시도는 반드시 필요한 루트 요청의 6회 실패 복구로, 개별 콘텐츠 상태 복구는 실제 TilesRenderer 객체를 사용하는 회귀 검사로 검증했다.

재실행: `npm run test:hong-kong:resilience`, `npm run qa:hong-kong:resilience`. 서버가 다른 포트이면 `HK_TEST_URL`을 지정한다.
