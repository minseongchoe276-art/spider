# 거미줄 고정 유지 수정

작업 시작일 2026-10-29, 계속 검증 2026-10-30. 기존 미완료 변경을 제외한 별도 검증본을 사용했다.

## 재현과 수정

- 기존 충돌 코드는 플레이어가 200m 이상 이동하여 같은 타일을 재가공할 때, 줄이 붙잡고 있는 기존 충돌체도 삭제했다. 기존 버전에서 재현 검사가 실패하는 로그를 보존했다. 이제 새 지역의 충돌 범위를 정상 갱신하면서도, 실제로 검증된 기존 고정점 충돌체는 소유 중인 줄이 놓일 때까지 별도로 유지한다. 마지막 소유자가 해제되면 즉시 정리한다.
- 실제 홍콩 플레이에서는 고정점에서 약 7.76m 떨어진 동일 외벽 삼각형에 줄 검사용 레이가 스치며 자동 해제됐다. 그 교차점과 고정점의 평면 차이는 약 0.005m였다. 같은 평면이라면 벽의 바깥쪽으로 20cm 이동한 레이로 경로를 다시 확인한다. 전체 메시를 통째로 무시하지 않으므로 뒤의 실제 장애물은 계속 차단한다.
- 낮은 고정점은 착지만 해도 버튼을 누르는 중에 해제됐다. 이제 줄과 고정점을 유지하며, 낮은 줄 때문에 자동 점프를 추가하지 않는다. 높은 줄의 기존 스윙 복귀 동작은 유지한다.
- 와이어 당기기에서 스윙으로 전환할 때 이미 검증한 충돌체를 즉시 새 줄에 전달한다.

## 검증

- 기존 버전의 충돌체 보존 검사 실패, 수정본 통과. 재가공이 이미 진행 중이던 경우와 부착 후 새로 시작되는 경우 모두 검사했다. 줄 해제 후 기존 충돌체가 남지 않는 것도 실제 Rapier로 확인했다.
- 같은 평면·반대 삼각형 방향·교체 LOD 이음새는 허용한다. 같은 메시 안의 수직 벽, 떨어진 평행 벽, 이음새 뒤의 다른 장애물은 계속 차단한다.
- 30/60/144 FPS에서 낮은 줄을 3초 유지하고 고정점과 길이가 변하지 않으며, 마우스를 놓으면 해제됨을 확인했다.
- 두 손 줄 18개, 플레이어 감사 12개, 진자 운동·수동 해제 운동량, 홍콩 충돌 10개 및 벽·추락 복구 검사를 통과했다.
- 실제 외부 홍콩 타일과 일반 마우스 입력 경로에서 8초, 16개 표본 모두 같은 고정점과 실제 충돌체를 유지했다. 도중에 카메라를 바꿔 LOD 변경도 유발했다.
- 충돌 재가공은 검사 전용으로 원래 타일의 범위 중심을 바꾸고 활성 상태에서 정상 재가공을 완료하는 fixture를 사용했다. 플레이어 위치·실제 삼각형·부착점은 바꾸지 않았다. 실제 200m 플레이 이동이나 FPS 벤치마크라는 뜻은 아니다.
- 유지 중 보호 충돌체 1개/소유 핸들 1개, 마우스 해제 후 둘 다 0개. 페이지·셰이더 오류 0건.
- 배포용 빌드 통과.

초안의 원거리 목표 탐색 이후 카메라 보간으로 다른 가까운 지점이 선택되던 검증은, 검증된 원거리 목표로 카메라만 조준한 후 정상 마우스 입력을 보내도록 바로잡았다. 또한 화면 밖의 오래된 타일은 원래 재가공하지 않으므로, 재가공 fixture에서 활성 상태와 완료 여부를 명시적으로 확인한다. 이 fixture를 실제 이동으로 보고하지 않는다.

진짜 경로 장애물, 사라진 실제 지지면, 사용자 마우스 해제에 따른 해제 규칙은 유지한다. 물리 모바일·홍콩 전체 장시간 검증은 포함하지 않는다.

재실행: `npm run test:web-continuity`, `npm run qa:web-anchors`. 브라우저 검사는 로컬 개발 서버와 기존 QA API를 쓰며 기본 포트는 5201이다.
