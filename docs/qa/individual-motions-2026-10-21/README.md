# 33개 모션 개별 검수 — 2026-10-21

최종 결과: **49/49 검증 묶음 통과**, 검사 중 소스 변경 없음. 빌드 통과. 현재 공개 캐릭터는 하나이며 두 게임 모드가 같은 외형을 사용한다. 기존 인간/변신 외형도 일부 호환 검사에서 추가 검증하지만 현재 제품의 모델 수로 세지 않았다.

## 수정 사항

- `drop`: 물리 상태가 이미 공중인데 지상 웅크리기/도약 준비를 재생하던 구간을 제외했다. 느린 낙하 → 빠른 낙하 선택을 3 FPS × 3 방향으로 검사했다.
- `roll`, `slamLand`: 발바닥뿐 아니라 손·무릎·어깨 등 몸 표면의 지지를 고려한다. 626개 표면 극점을 한 번 준비하고 공유하며, 실행 중에는 그 점만 검사한다. 별도 검증은 실제 스킨 정점 **29,133개 전체**를 검사한다.
- 중간에 구르기/착지를 끊어도 접촉 높이를 즉시 버리지 않고 해제한다. 걷기/점프 전환 12건을 검사했다.
- 검수 자료 추출기는 폐기된 외형 대신 현재 공개 모델을 측정하고, 모델·리타게팅 코드까지 해시로 기록한다.
