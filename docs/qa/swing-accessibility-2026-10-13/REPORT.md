# 거미줄 이동 접근성 수정 검증 — 2026-10-13

온라인 키보드 이동, 낮은 조준, 바닥 스윙 시작 및 E 연속 사용을 수정했다.

## 변경

- 플레이 중 로비 버튼의 포커스가 WASD를 가로채지 않도록 수정. 입력 칸에서의 타이핑은 계속 게임 입력에서 제외한다.
- 서버 위치 보정 후 누르고 있던 이동 키를 유지하며 낙하/지지 상태를 다시 평가한다.
- 조준 보조에서 낮은 벽보다 몸 위 7m 이상의 실제 부착 표면을 우선한다. 위쪽 및 좌우 탐색 범위를 확대했다. 보조를 끄면 직접 조준을 유지한다.
- 첫 바닥 발사에 점프와 전진을 적용하고 줄을 초당 14m 이내로 점진적으로 감아 스윙 최저점을 지면 위로 올린다. 공중 재부착은 점프 추진력을 추가하지 않는다.
- 줄이 느슨할 때도 이동 입력이 적용된다. 팽팽한 줄에는 접선 방향 힘을 적용하고, 놓을 때 관성을 유지한다.
- E는 착지 제한을 없애고 0.28초 간격으로 반복 가능하다. 누르고 있어도 반복되며 한 발의 이동 목표는 최대 18m, 당김 시간은 최대 0.85초이다. 이후 관성 이동은 유지된다.
- 조작 가이드를 변경된 동작에 맞게 수정했다.

## 자동 검증

- `npm test`: 기존 전체 회귀 검사 통과. 로그: full-tests.log.
- `npm run test:swing`: 추가된 8개 묶음 시나리오 통과. 로그: swing-tests.log.
- `npm run build`: 성공. 기존의 번들 크기 안내 경고가 있다. 로그: build.log.
- 30/60/144FPS 바닥 출발 및 4초 스윙 결과 일치, 궤적의 바닥 관통 방지, 줄 반경 제약, 관성 해제 확인.
- 반복 E의 18m 목표 제한, 연속 사용, 장애물 차단 및 실패 후 재시도 확인.
- 실제 StreamedCollision 삼각형/Rapier 캡슐로 바닥 점프 스윙과 E 연결 확인.
- 버튼 포커스 상태의 W와 서버 보정 후 계속 이동, 입력 칸 타이핑 격리 확인.

## 브라우저 검증

`http://127.0.0.1:5188/?city=procedural`의 실제 Chrome 플레이를 확인했다.
혼자 플레이에서 W 이동, 첫 거미줄 발사 후 상승, E를 유지한 웹 집을 확인했다.
두 번째 브라우저 탭으로 방에 참가하여 양쪽 준비/경기 시작을 수행했다. 경찰과 도망자 배정, 도망자 WASD 이동, 거미줄 발사와 E 이동을 확인했다. 도망자의 미니맵 위치는 W로 북쪽 -157m에서 -161m로 이동했고 이후 E 사용으로 -193m 부근까지 진행하면서 고도 100m를 기록했다.

## 범위 및 한계

이번 브라우저 검증은 로컬 도시와 로컬 WebSocket 방 서버에 해당한다. 스트리밍 지형은 실제 물리 엔진의 자동 회귀 검사로 확인했다. 외부 운영 사이트 배포 또는 외부 Supabase 경도 경기의 동일 변경 적용을 이 기록이 증명하지는 않는다. 모든 지형/장치에서 완벽하다는 보증은 하지 않는다. 마지막 추가 화면 저장은 브라우저 연결 종료로 완료하지 못했다.
