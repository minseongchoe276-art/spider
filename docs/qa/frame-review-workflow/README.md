# 무기·모션 프레임 검수 계획

## 범위와 판정

실제 게임에서 가능한 무기·상태·행동과 중단·복귀 조합을 게임 규칙을 기준으로 목록화한다. 각 시나리오에 입력, 장착 모델, 외형, 지형, FPS, 시작·종료 조건과 소스 버전을 기록한다. 불가능한 조합은 이유를 명시하고 제외한다. 목록이 완성되기 전에는 전체 조합 완료를 주장하지 않는다.

각 시나리오의 프레임을 정면·측면·후면에서 검토한다. 손가락과 무기 손잡이의 접촉, 손목·팔꿈치·어깨의 자세, 팔과 몸·무기·환경의 관통, 프레임 간 움직임과 회복을 확인한다. 정지 화면만으로 판정하기 어려운 경우 앞뒤 프레임과 정상 속도 재생을 함께 확인한다. 검토자가 확인한 프레임만 확인 처리하고, 문제에는 시점·프레임·설명과 이미지를 남긴다. 자동 수치 통과는 육안 통과가 아니다.

수정 시 문제의 재현 조건과 변경 전후 이미지를 보존하고, 해당 구간과 인접 전환, 24·30·60·144fps의 관련 회귀 검사를 다시 수행한다. 최종 보고에는 전체 시나리오 수, 완료·문제·미검수 수, 사용한 버전과 미검증 조건을 기록한다.

## 현재 도구와 한계

개발 서버의 `?motionLab` → 프레임 육안 검수에서 선택한 무기·상태·동작의 `Character.update` 출력을 60fps로 기록하고 프레임과 시점을 변경할 수 있다. 손 확대, 시점별 확인·문제·메모, PNG 저장, JSON 내보내기를 지원한다. 수치 오류는 별도로 표시한다. 각 기록은 생성 시각으로 구분되며 이전 기록의 판정을 새 기록에 복사하지 않는다.

이 기록은 고정된 속도와 상태를 입력한 **시뮬레이션**이다. 실제 게임의 지형·충돌, 와이어 고정점, 무기 교체·중단 입력, 온라인 상태를 재현하지 않는다. 회복 구간은 지정된 상태에서 행동을 해제한 구간이며 실제 입력 전환 전체를 대표하지 않는다. 자동 생성된 조합 목록과 시나리오별 완료 집계는 아직 없다. 저장된 판정은 브라우저에 남지만 기록된 자세 자체는 새로고침 후 복원되지 않는다. 증거 이미지는 별도로 내려받아야 하며 JSON에 자동 포함되지 않는다. 개발 소스 식별자는 `development`이므로 정확한 커밋과 로컬 변경 여부를 별도로 기록해야 한다.

## 후속 작업

1. 게임 입력과 규칙에서 유효한 조합·전환 목록을 생성하고 누락과 불가능한 조합을 검증한다.
2. 실제 물리·지형·고정점 및 장착·피격·회피 중단을 재현하는 독립 시나리오와 재실행 가능한 프레임 기록을 만든다.
3. 시나리오·프레임별 정면·측면·후면 증거 및 판정의 저장·복원, 버전 식별과 전체 진행률을 구현한다.
4. 각 조합을 육안으로 검수하고 발견한 문제를 수정·회귀 검증한다.
