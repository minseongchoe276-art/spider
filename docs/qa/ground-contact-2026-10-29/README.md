# 캐릭터 접지·발 관절 정밀 점검 — 2026-10-29

## 확인된 문제와 수정

### P0. 홍콩 맵의 보이지 않는 옛 바닥

화면에 보이는 상세 지형보다 위에 있는 이전 LOD의 충돌 지형이 남았다. 발 IK는 그 충돌면을 정확히 따라갔으므로 모델의 높이만 낮추는 방식으로 해결할 수 없는 문제였다. 기존 교체 조건은 새 지형과 옛 지형의 높이 차이가 25cm 미만이어야 했다. 원본 사진 측량 LOD 사이의 차이가 이를 넘으면 옛 바닥이 계속 유지됐다.

`src/StreamedCollision.js`에서 상세 지형의 충돌 생성이 끝나고, 캐릭터 중심과 발밑 주변 네 지점 모두 걸을 수 있는 경사의 표면으로 덮인 경우에만 옛 지형을 해제한다. 하향 높이 차이를 최대 1.25m 범위에서 허용한다. 일부만 로딩된 지형, 빈 공간, 급경사는 교체 대상으로 승인하지 않는다. 복구용 지지면도 새 충돌면으로 이관한다.

새 회귀 검사에서는 90cm 낮은 상세 바닥으로 교체되는지, 폭 10cm의 불완전한 대체면 때문에 원래 바닥이 먼저 사라지지 않는지 함께 검증했다.

### P1. 스트레이트 공격 시 뒷발의 옆 꺾임

원본 동작이 뒤꿈치를 들면 발목 높이만으로 만든 접촉 판정이 뒷발을 공중으로 분류했다. 실제로는 뒷발이 지지해야 하는 자세인데 접촉이 해제되어, 발목 제한과 평평한 발 IK가 충돌했다.

`src/CharacterPose.js`에서 잽·크로스의 낮게 유지된 뒷발을 지지 후보에 포함했다. 기존의 지형 존재·관절 도달 거리·동작 가중치·회전 및 발 교차 검사를 그대로 통과해야 한다. 이 경로에서 기존의 짧은 뒷발 지지 자세가 적용된다. 발목 18도·발가락 5도의 기존 관절 제한을 늘리지 않았다.

웹 동작에서 크로스로 전환하는 24 FPS 재현에서 뒷발 옆 기울기는 **17.665도 → 0.244도**로 감소했다. 24/60/144 FPS, 왼손·오른손·양손 웹 전환의 크로스 9개 조건에서는 최댓값이 **1.190도 미만**이었다.

## 실제 플레이 측정

로컬 Chrome에서 실제 게임을 실행하고 키 입력으로 홍콩 맵과 기본 도시를 이동했다. 뼈의 발목 위치만 비교하지 않고, 렌더링되는 스킨 메시의 부츠 정점과 실제 표시 지형의 교차점을 비교했다. 아래 값은 각 동작의 7회 표본에서 양발 중 낮은 발의 지면 간격 중앙값이다. 들어 올린 발과 점프·구르기의 공중 자세를 접지 실패로 세지 않았다.

| 홍콩 맵 표본 | 수정 전 | 최종 측정 |
|---|---:|---:|
| 정지 | 89.18cm | 0.60cm |
| 일반 이동 | 106.82cm | 0.41cm |
| 전력 질주 | 공중·구르기 혼재로 직접 비교 제외 | 0.31cm |
| 이동 후 정지 | 바닥 교차점 누락 표본으로 비교 제외 | 0.30cm |
| 방향 전환 | 바닥 교차점 누락 표본으로 비교 제외 | 2.83cm |
| 전투 이동 후 정지 | 48.80cm | 2.06cm |

서로 다른 플레이 실행에서 스트리밍 시점과 도착 위치가 달라질 수 있다. 위 수치는 전 맵의 최악값이나 동일 픽셀 화면의 차이를 뜻하지 않는다. `before.json`, `final.json`에 개별 발·물리 높이·시각 표면·상태·관절 각도·지지 발 수명과 측정값을 저장했다.

실제 키 입력 플레이에서 이동, 전력 질주, 점프, 착지 후 정지, 전투 전환, 차량 탑승과 하차를 확인했다. 차량은 탑승 상태 진입과 하차 후 접지를 확인했으며, 이 장면에서 차량 주행 거리 검증을 완료했다고 주장하지 않는다. 브라우저 예외와 셰이더 오류는 기록상 0건이다.

## 남은 품질 한계

사진 측량 원본의 거친 지형과 LOD 사이의 모양 차이 자체를 없앤 것은 아니다. 경계에서 작은 높이 변화와 발 접지 전환이 남을 수 있으며, 실측 방향 전환과 전투 정지 표본에는 약 2~3cm 간격이 남았다. 원본 모션의 무릎 궤적·보폭·스타일과 외형의 스키닝 품질 전체를 새로 제작한 작업도 아니다. 달리는 동안 들어 올린 발의 회전을 모두 0도로 만들면 자연스러운 보행이 손상되므로 그런 보정은 적용하지 않았다.

이번 검증은 로컬 Chrome과 자동 리그 검사 범위다. 실제 모바일 기기, 모든 홍콩 좌표, 온라인 다른 플레이어의 지연된 자세를 전수 검증한 결과는 아니다. 기존 작업 중 변경 파일들은 유지했으며, 이번 수정은 아직 별도 커밋·푸시하지 않았다.

최종 실행 결과: 위 검증 모두 통과. 실제 플레이 최종 결과는 `play-final.json`의 `status: PASS`이며, 지면에서 공중으로 이탈하고 복귀한 상태와 실제 차량 탑승·하차 상태를 기록했다.
