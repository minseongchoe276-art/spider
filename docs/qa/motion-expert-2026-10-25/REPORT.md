# 모션 전수 검수 — 2026-10-25

## 확인한 결함과 수정

`Character.stopAnimation()`은 Three.js 클립만 정지시키고, 믹서 밖에서 적용하는 몸 기울기·발 접지·상체 공격·관절 속도 제한의 이전 기록을 남겼다. 스윙 중 재시작한 캐릭터와 새 캐릭터를 같은 입력으로 비교하면 자세가 달라졌다. 수정 전 새 회귀 검사에서는 24 FPS 스윙 후 복귀 구간에서 최대 315.79mm 차이로 실패했다.

재시작 시 자세 보정의 이력을 함께 정리했다. 일반적인 동작 전환의 크로스페이드와 IK는 유지하며, 리셋 후에는 현재 상태에서 보정을 다시 계산한다. 캐릭터의 목표 바라보기 방향과 게임플레이가 소유하는 전투·와이어 입력은 유지한다.

`scripts/check-motion-reset.mjs`는 24·30·60·144 FPS에서 스윙, 와이어 집, 벽 이동, 달리면서 공격, 구르기 후 리셋을 검사한다. 첫 프레임과 이후 0.3초의 머리·골반·양손·양발을 새 캐릭터와 비교한다. 20개 경우 모두 0.01mm 이내로 일치했다. `npm run test:motion-reset`과 기본 `npm test`에 연결했다.

## 검사 범위

전체 모션 검사 실행기를 49개에서 58개 검사 묶음으로 확장했다. 최근 구르기·전투 복귀, 벽 머리 간격, 실제 이동·카메라, 이동 중 공격·회피·피격 조합, 모바일 이동, 입력·지형·보행 검사와 이번 리셋 회귀 검사를 포함한다.

등록 모션은 33개다. 모든 클립의 시간축, 클립 쌍의 전환, 두 외형의 최종 스킨, 발 접지, 관절 제한, 사지 비틀림, 벽·난간·계단·경사면, 공중 동작, 양손 와이어, 이동 전투, 원격 자세를 검사한다. 각 검사에 선언된 FPS와 허용 범위를 적용하며 모든 검사가 동일한 FPS 행렬을 사용하는 것은 아니다.

브라우저의 실제 WebGL 검수 화면에서 벽 → 난간 → 옥상 달리기, 낙하 → 구르기, 스윙 → 해제 → 낙하, 질주 중 잽 장면을 재현해 확인했다. 이 육안 검사는 대표 구간이며 전체 클립의 모든 프레임을 육안으로 관찰했다는 의미는 아니다.

## 최종 판정

58개 검사 묶음 모두 통과했다. 다만 전체 검사 실행 중 별도로 진행되던 모바일 작업에서 `src/MobileTraversal.js`, `src/Multiplayer.js`, `src/main.js`가 변경돼 실행기의 소스 일관성 검사는 실패했고, 실행기는 종료 코드 1을 반환했다. 이를 전체 실행 성공으로 숨기지 않고 `source-integrity.json`에 그대로 보존한다. 캐릭터 모션 본체·모션 트랙·외형 파일의 변경은 감지되지 않았다.

최종 모바일 변경을 포함한 상태에서 모바일 이동, 멀티플레이어, 원격 모션, 세션 흐름, 입력 수명 주기, 이동·카메라 연결, 실제 이동·카메라, 모션 리셋의 8개 검사 묶음을 추가 실행해 모두 통과했다. 추가 검사 전후 전체 `src/*.js` 해시가 일치했다. 최종 프로덕션 빌드와 `git diff --check`도 통과했다. 빌드는 번들 크기 경고를 출력한다.

## 결과 파일과 재현

- `suite-results.json`: 수정 후 전체 검사 결과
- `source-integrity.json`: 전체 검사 전후 런타임 소스·모션·외형 해시
- `manifest.json`: 모션·검사 범위
- `build.log`: 프로덕션 빌드 출력
- `final-integration/results.json`: 최종 소스 상태의 추가 검사 8개와 소스 해시
- `acceptance-summary.json`: 검사 결과와 빌드 후 최종 파일 해시 일치 여부
- `baseline-partial.json`: 수정 전 통과한 30개 검사 기록. 결함 재현 후 수정본 검수로 전환해 중단한 기초 검사이며 전체 통과 기록이 아니다.

```sh
npm run test:motion-reset
MOTION_AUDIT_DIR=docs/qa/motion-expert-2026-10-25 MOTION_AUDIT_DATE=2026-10-25 node scripts/run-motion-audit.mjs
npm run build
```

자동 검사는 명시한 상태·입력·지형 조합을 검증한다. 임의의 모든 지형, 네트워크 지연, 입력 순서 및 예술적 자연스러움의 절대적 완벽함을 보장하지 않는다. 공개 서버 배포는 이번 작업에 포함하지 않았다.
