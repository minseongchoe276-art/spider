# SHADOW PULSE 운영 게임 검증 프롬프트

대상: https://minogame.site/?city=procedural&view=online

숙련된 게임 QA 담당자로서 실제 운영 빌드를 별도 브라우저에서 검증한다. 우선 표시된 버전과 접속 환경을 기록하고, 로컬 소스 검사 결과를 운영 빌드의 실행 결과와 구분한다. 기존 사용자 데이터와 다른 플레이어에게 영향을 최소화하며 식별 가능한 임시 테스트 방을 사용한다. 유료 기능, 계정·권한 변경, 관리자 기능이나 타인에게 메시지 전송은 별도 승인 없이 하지 않는다.

1. 초기 로딩, 빈 화면·오류·재시도, 언어 및 좁은 화면 배치를 확인한다.
2. 이름과 방 코드의 빈값·잘못된 값, 방 생성 옵션과 자유 플레이, 방 목록·입장·퇴장·재입장을 점검한다. 가능하면 독립된 두 세션에서 참여자 표시, 움직임·자세·공격·접속 종료와 복구를 양쪽 화면에서 비교한다. 테스트 방은 사용 후 나간다.
3. 게임 진입 후 이동·방향 전환·정지·달리기·점프·낙하·착지·회피·공중 기술·벽 이동·턱 오르기·카메라 및 충돌을 각각 시험한다. 지상/공중, 입력 전환 및 연속 입력에서도 발 미끄러짐, 관절 뒤틀림, 팝, 관통, 카메라 가림을 확인한다.
4. 모드 전환, 좌우 와이어 발사·부착·스윙·해제·양손, 집, 근접 공격·방어 및 무기 관련 동작을 사용 가능한 범위에서 시험한다. 입력과 결과의 일치, 전환과 회복, 시각·음향 피드백을 확인한다.
5. 도움말, 일시정지·재개, 포커스 이탈 및 복귀, 설정·언어·창 크기, 조작 안내와 실제 입력을 검증한다. 가능하면 다른 브라우저·모바일·게임패드 및 저속 네트워크도 별도 확인한다.
6. 콘솔 오류와 로딩·프레임 이상을 관찰하고 재현 가능한 결함은 환경, 단계, 기대 결과, 실제 결과, 심각도와 증거를 기록한다. 실패나 막힌 기능을 성공으로 표시하지 않는다.
7. 관련 자동 검사는 기존 작업과 데이터를 보존하면서 실행하고 실제 운영 화면 관찰과 구분한다. 변경이 필요하면 원인을 확인하고 최소한으로 수정한 뒤 같은 절차로 회귀 검증한다. 배포·커밋·푸시는 명시적 요청 없이 하지 않는다.
8. 항목별 통과/실패/미검증 및 이유와 범위를 보고한다. 유한한 시험으로 모든 조합이나 주관적인 완벽함을 보장한다고 주장하지 않는다.
