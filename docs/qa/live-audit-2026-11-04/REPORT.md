- 통과: 한국어 온라인 로비 로딩, 자유 플레이 방 생성, 다른 탭의 방 목록 표시 및 입장, 두 명의 준비 상태와 시작 조건, 경기 진입.
- 통과: 양쪽 플레이어 표시, W 이동 후 양쪽 거리 표시 14m → 2m, Space 점프 시 고도 변화, X 전투 모드 전환, 도움말 열기/닫기, Esc 메뉴와 재개, 전체 지도 열기·확대 1× → 2×.

- 제한적 확인: 전투 Q/E/T/G 입력 후 기력 변화를 관찰했지만 각 애니메이션의 전 구간·명중·판정을 개별 확인하지 못했다. 공중 E 입력은 시도했지만 실제 부착과 목표 지점 도달을 확인하지 못했다. 브라우저에 기록된 경고·오류 로그는 없었다.

## 발견한 불일치와 로컬 수정

1. 운영 조작 가이드는 카메라 정렬 키를 X로 표시한다. X는 모드 전환이고 기본 정렬 키는 Z다. `index.html` 표기를 Z로 변경했다.
2. 운영 전투 HUD의 E 버튼은 강공격이라고 표시하지만 E는 오른쪽 회피다. `src/main.js` 라벨을 오른쪽 회피로 변경했다.
3. 로컬 개발 서버에서 변경 후 Z 안내와 E 오른쪽 회피 라벨을 실제 브라우저로 확인했다. 운영 사이트에는 아직 배포하지 않았다.
