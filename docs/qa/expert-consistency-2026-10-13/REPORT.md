검증 증거:

- `before.json`: 최초 6개 상태 오류의 수정 전 실패.
- `additional-before.json`: 혼자 플레이 복귀·레이스 완료 기록의 추가 실패.
- `after.json`: 9개 상태 회귀 검사 PASS.
- `reconnect-before.log` / `reconnect-after.log`: 자유 플레이 참가자 삭제 실패 → 실제 WebSocket 복귀·종료 후 만료 PASS.
- `test.log`: 기존 전체 테스트와 추가 상태 검사의 실행 기록.
- `build.log`: 빌드 성공. 약 5.63MB 번들 크기 경고는 남아 있다.
- `browser.json`: 두 실제 브라우저의 자유 플레이 이동·새로고침·동일 ID와 위치 복원 PASS. 탈락 후 관전 진입은 동일 브라우저의 서버 스냅샷 경로에 탈락 상태를 주입한 검사이며 실제 피해·서버 탈락 검증과 구분한다. 관전 후 혼자 플레이의 캐릭터 표시 PASS. 페이지 오류 0개.

검수 도중 공유 작업 폴더에서 별도의 PostgreSQL·이동 예산·구조 규칙 수정이 진행되고 있었다. 그 의존성·DB 마이그레이션·규칙 변경은 이번 배포에 포함하지 않는다. 기존 커밋과 이번 수정만 담은 독립 체크아웃에서 최종 테스트·빌드를 확인한다.

홍콩 경쟁전의 기존 피해자 클라이언트 지형 확인 의존은 이번 수정 범위에 포함하지 않는다. `hong-kong-security.log`는 새 로컬 테스트 서버에만 실행한 별도 진단이며, 운영 서버 공격 검사나 운영 DB 변경을 수행하지 않았다. 서버의 신뢰 가능한 홍콩 충돌·시야 판정과 경쟁전 검증은 별도 해결 및 검증이 필요하다. 이 제한 때문에 전체 무결함으로 판정하지 않는다.

최종 배포본 검증: 별도 체크아웃에서 `npm test`(추가 두 회귀 검사 포함), `npm run build`, 두 브라우저 자유 플레이 재접속 및 탈락 스냅샷·혼자 플레이 표시 검사 PASS. `release-test.log`, `release-build.log`, `release-browser.json`에 보존했다.
