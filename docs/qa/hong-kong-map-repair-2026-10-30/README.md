# 홍콩 지도 렌더링 수정 진행 기록

수정한 결함:
- 중복 삼각형 검사에서 정점 순서를 정렬하여 정상적인 반대 방향 면까지 삭제하던 경로를 수정했다. 보행교·얇은 벽의 양쪽 면과 UV·노멀·색상 등 속성 경계를 보존한다.
- 노멀 재생성 시 공유 원본 지오메트리를 즉시 해제하던 경로를 참조 수에 따라 해제하도록 수정했다. 원본을 쓰는 메시가 남으면 보존하고 모두 대체됐을 때 한 번 해제한다.

검증:
- `node scripts/check-tile-face-integrity.mjs`: 면 방향, 중복 면, 재질 경계, 잘못된 인덱스, 퇴화 면, 경계값, 공유 버퍼 수명 통과.
- 프로덕션 빌드 통과 (`build.log`).
- 실제 외부 홍콩 타일을 사용하는 Chrome에서 중심부 9개 지지 표면을 방문하고 화면·로드된 메시 속성·셰이더 예외를 기록했다 (`play.json`, `view-*.png`). 낮의 맑은 날씨를 명시적으로 고정했다. 높이는 실제 충돌 지형에서 탐색했으며 이동·점프도 실행했다.
- 추가 재점검: 잘못된 UV 값은 유한 좌표로 복구하고 잘못된 노멀은 재계산하여 NaN이 셰이더로 전파되지 않도록 했다. 이 처리는 원본의 손실된 텍스처 디테일을 복원하는 기능은 아니다.
- 기존 렌더링 검사의 기대값을 현재의 근거리 상세도 유지 정책과 교체 후 실제 메시 기준으로 수정했다. `check-hong-kong-rendering.mjs` 전체 검사와 신규 지오메트리 검사가 통과했다.

남은 작업:
화면에서 원본 사진 측량의 각진 지형·수목 덩어리·늘어진 벽면이 여전히 보인다. 이 작업으로 홍콩 전체의 누락·깨짐을 모두 해결한 것은 아니다. 4.8km 폭의 플레이 구역 전체를 방문한 것도 아니다. 개별 원본 형상 결함은 정확한 교체 모델과 경계·충돌 검증이 추가로 필요하다. 기존 다른 미커밋 작업을 보존했으며 이번 변경은 아직 커밋·푸시하지 않았다.
