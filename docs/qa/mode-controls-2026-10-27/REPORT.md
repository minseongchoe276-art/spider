전투 모드의 공중 공격·집 이동은 발동하지 않는다. 기존 기력·쿨타임·지형·판정 조건이 충족되어야 기술을 사용할 수 있다. 전투 중 Q는 현재 공격의 회복 구간까지 마친 뒤 전환하며, 다시 Q를 누르면 전환 예약을 취소한다. 기존 경찰과 도망자의 도망자 모드 고정 규칙은 유지한다.

G 특수공격, R/T 공중제비, C 웅크리기 및 별도 강공격·내려찍기 버튼을 일반 조작·설정·터치 UI에서 제외했다. X/V 카메라 조작은 유지한다. 기존 모션 파일과 네트워크 호환용 동작은 삭제하지 않았다.

## 성능 및 남은 검증

입력 갱신은 기존·수정 후 코드를 각각 워밍업 후 100,000회 × 7회 측정하고 중앙값을 `performance.json`에 기록한다. 마이크로벤치마크이며 실기기 GPU FPS 개선을 뜻하지 않는다. 프레임마다 새 IK를 실행하거나 리그 연산을 추가하지 않았다.

8개 네트워크 클라이언트 자동 검증과 실제 8명이 각 장치에서 플레이하는 시각·프레임 검증은 구분한다. 실제 Android/iOS/게임패드, 8명 동시 렌더링 FPS, 원본 모델 전체의 Blender Bone Roll·예술적 해부학적 평가는 UNVERIFIED다.
