경기 규칙
경찰과 도망자2~8명. 6명 이하는 경찰 1명, 7~8명은 경찰 2명. 시작 8초는 공격 없음. 경찰 주먹 25, 에너지 와이어 15. 도망자는 공격할 수 없습니다. 도망자가 모두 쓰러지면 경찰 승리. 이동 목표 3개를 완료하거나 3~5분 생존하면 도망자 승리. 쓰러진 팀원 곁에 3초 유지하면 구조합니다. 탈락하면 관전합니다.
터치 조작
터치 조작왼쪽 스틱으로 이동하고 끝까지 밀면 질주합니다. 거미줄 버튼을 한 번 누르면 앞쪽 건물에 연결되고, 다시 누르면 놓습니다. 초록 표시는 연결 가능한 지점입니다. 카메라는 진행 방향을 부드럽게 따라갑니다. 오른쪽 화면을 밀면 직접 시점을 조절하며 수동 조작이 우선합니다. 점프 버튼은 줄을 놓고 도약합니다. 전투·보조 와이어·벽 이동·묘기는 더보기에서 엽니다.
