# 실제 조작·거미줄 후속 점검 — 2026-10-13

기존 전체 검사는 통과했지만, 실제 버튼 순서를 추가로 재현하니 거미줄 관련 문제 6개가 발견됐다. 현재 로컬 코드에서 수정했고, 새 검사 10개와 전체 회귀 검사, 빌드를 통과했다. 따라서 이전 상태를 완벽하다고 판단할 수 없었으며, 이번 결과도 모든 입력·장비에서 무결점이라는 보장은 아니다.

## 발견한 문제와 수정

| 재현 조건 | 수정 결과 |
|---|---|
| 좌클릭→우클릭→좌클릭 해제→좌클릭 재입력 시 남아 있던 우클릭 손의 줄을 덮어씀 | 버튼이 현재 사용하는 손 또는 반대 버튼이 사용하지 않는 손을 선택한다. 유지한 줄의 부착점·길이는 바뀌지 않는다. |
| 양손 사용 후 좌클릭을 해제하고 우클릭을 재발사하면 우클릭 소유 줄이 두 개로 늘어남 | 실제 버튼 발사는 같은 버튼의 이전 줄을 교체하며, 버튼 하나에 줄 하나를 유지한다. |
| 방금 발사한 줄이 장애물에 끊겨도 발사 타이머가 줄을 계속 그림 | 살아 있는 손 부착 정보와 발사 타이머·지속 줄 목표를 동기화한다. 사라진 줄을 다시 그리지 않는다. 팔 자세는 기존 감쇠를 유지한다. |
| 집→스윙 전환에서 부착점 쪽으로 움직이는 속도까지 제거함 | 팽팽한 줄에서 바깥 방향 속도만 제거한다. 허용되는 안쪽 속도와 접선 속도를 보존한다. |
| 자동 목표 탐색에서 가장 점수가 높은 건물이 막히면 도달 가능한 다른 건물도 선택하지 못함 | 가려지지 않은 부착점만 순위에 넣는다. |
| 집 도중 줄 경로에 새 장애물이 생겨도 부착점 자체가 유지되면 계속 당김 | 각 물리 스텝에서 집의 줄 경로와 부착점 지원을 검사하고, 막히면 줄·목표를 정리하고 자유 비행으로 전환한다. |

구현: `src/SwingPhysics.js`. 새 회귀 검사: `scripts/check-player-audit.mjs`. 기존 `check-dual-web.mjs`의 양쪽 건물 조준 사례는 현재 사용자 조작인 좌·우 버튼 유지로 바꿨다. `npm test`에 새 검사를 포함했다. 작업 전부터 존재하던 수정 사항은 유지했다.

## 판정과 범위

고정 부착점·고정 길이, 양손 줄의 독립성, 줄이 느슨할 때 밀어내지 않는 제약, 일반 해제의 관성 보존, 장애물/LOD 소실 해제, 집 종료, 실제 리그의 손 도달과 상태 전환을 검사했다. 확인한 문제는 수정했으나 거미줄 전체가 완벽하다고 단정하지 않는다.

이번 브라우저 확인은 혼자 플레이와 짧은 홍콩 스윙 전환이다. 장시간 도시 전체 탐색, 모든 건물에서의 벽/줄/카메라 조합, 인터넷 환경의 다인 지연·재접속, 공개 배포본 적용 여부는 별도 검증 범위다. 모션 수치 검사 통과는 모든 시점에서의 미적 자연스러움을 보장하지 않는다.

동시에 여러 게임 탭과 회귀 검사를 실행하던 환경에서 홍콩 HUD에 18~24 FPS가 관측됐다. 단일 게임 실행 성능 벤치마크는 아니며, 낮은 사양에서의 프레임 성능과 큰 번들 최적화는 미완료다.
