# 전투 및 전체 모션 손발 관절 수정 · 2026-10-20

33개 등록 모션의 최종 손목·발목·발가락 출력과 두 외형을 검사했다. 이번 추가 재검수에서는 제자리 회전과 회전 → 대기 전환에서 종아리가 순간적으로 비틀리는 문제도 찾아 수정했다.

## 수정 내용

- 손목은 바인드 자세의 기울기 대신 실제 전완–가운데 손가락 관절의 직선을 기준으로 제한한다. 손목 12°, 발목 18°, 발가락 5°와 각 관절의 시간당 회전 제한을 최종 IK·접촉 보정 뒤에 적용한다.
- 벽 등반에서는 벽 법선의 전완 수직 투영이 거의 사라지는 구간에서 이전 손바닥 방향을 유지한다. 손목을 꺾어 벽을 짚지 않고, 손끝 접촉과 전완 회전으로 방향을 맞춘다.
- 발 지지의 회전 기준을 유지하고, 고정 자세에서 반복 IK 때문에 발이 서서히 움직이는 피드백을 제거한다. 실제 부츠 정점을 이용해 바닥 관통도 보정한다.
- 제자리 회전 중 고정된 발을 해제할 때 지지 방향이 새 몸 방향으로 즉시 바뀌던 처리를 수정했다. 요청된 지지 방향을 최대 240°/초로 이어 주며, 렌더링 후 제한된 발 회전을 다음 목표로 되먹임하지 않는다.
- 대기 클립에는 접촉 창이 없으므로, 회전이 끝난 첫 프레임에서 지지 보정을 버리던 문제도 수정했다. 대기 전환까지 같은 지지 기준을 풀어 준다. 목표 회전을 정규화하여 이미 정착한 자세를 계속 미정착으로 판단하지 않게 했다.
- 리셋·공중 이동·모델 교체 시 지지 회전 이력을 해제한다. 보정 중인 자세는 고정 자세 캐시에 조기에 저장하지 않는다.
- 재생 자료를 생성할 때 좌우 회전 방향을 실제 `SwingPhysics.turnOnSpot()`의 부호와 일치시켰다.

## 재현한 문제

[수정 전 회전 검사](turn-before.json)는 두 외형 × 24/30/60/144 FPS × 네 시작 방향 × 좌우 회전의 64개 사례를 검사한다. 회전 후 대기로 돌아가는 구간도 포함한다. 별도 복사본에서 이번 지지 방향 보간과 대기 전환 유지 처리만 제거했으며, 나머지 관절 보정은 유지했다. 복사본과 최종 코드 사이의 [수정 차이](support-fix.patch)를 함께 보관한다.

팔다리의 굽힘·이동은 평행 운반으로 제거한 뒤 남은 종아리 축 회전을 측정한다. 발목의 로컬 회전만 검사하면 이 문제를 놓친다. 수정 전 64개 사례가 모두 실패했고 최대 축 회전 속도는 약 10,795°/초였다.

- [전투 발 지지](combat-feet.json): 이동·공격 45개와 고정 자세 75개, **총 120개 통과**. [이동 전투 스킨 검사](moving-combat-skin.json)도 통과했다.
