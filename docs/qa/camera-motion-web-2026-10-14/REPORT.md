# 카메라·모션·거미줄 집중 점검 — 2026-10-14

현재 작업 파일을 기준으로 카메라의 초기화·모드 전환·충돌·흔들림, 모션 블렌딩·도약 팔 자세, 양손 거미줄의 발사·실패·해제·렌더 순서를 점검했다. 기존 작업 변경을 보존하고 관련 코드만 보완했다.

## 확인된 결함과 수정

| 영역 | 원인과 영향 | 수정 |
|---|---|---|
| 1인칭 초기화 | 카메라 위치와 lookAt 목표가 같아 초기화 직후 -Z를 보고, 캐릭터 방향을 잃음 | 목표를 캐릭터 전방으로 설정 |
| C로 시점 복귀 | V 전환과 달리 1인칭 pitch를 반전·제한하지 않아 과도한 붐 각도가 남음 | 공통 setMode에서 부호 변환·범위 제한 |
| 충격 흔들림 | 1인칭 분기가 감쇠 전에 반환하여 예전 충격이 3인칭 복귀 후 재생됨 | 1인칭에서도 충격 강도 감쇠 |
| 1인칭 거미줄 | 손은 카메라 자식인데 줄을 카메라 이동 전에 그려 고속 이동에서 한 프레임 뒤처짐 | 카메라 이동 후 손 끝점 갱신 |
| 빠른 모션 변경 | fade-in 도중 fadeOut이 가중치를 1부터 시작하여 부분 자세가 갑자기 강해짐; 수정 전 0.1667→1 재현 | 현재 유효 가중치에서 fade-out 시작 |
| 반대 손 발사 실패 | 물리 동기화가 부착점 없는 실패 발사의 타이머를 지워 표시·팔 뻗기 소실 | 실패 발사를 실제 부착과 구분, 표시 시간 동안 유지하고 만료 시 제거 |
| 도약 중 연결된 팔 | 실제 줄이 연결되어도 애니메이션 상태 JUMPING에서는 발사 타이머만 기준으로 팔 자세를 처리 | 실제 손별 부착점을 우선하여 도약 중에도 뻗기 유지 |

실패 발사를 유지하는 변경은 실제 물리 부착점을 추가하지 않는다. 실제 줄이 장애물로 끊어진 경우의 즉시 숨김도 별도 재현 검사로 확인했다.
