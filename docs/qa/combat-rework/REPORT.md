# 전투 모션 재구성

2026-10-11. 이전 검증은 관절·접지·타이밍의 오류를 주로 검사했으며, 전투 안무가 자연스럽거나 멋있다는 근거로 충분하지 않았다. 실제 렌더링에서 잽의 교차하는 다리와 벌어지는 반대팔을 확인했다.

기본 전투 자세, 잽, 스트레이트, 훅, 강공격, 방어의 6개 클립을 실제 스파이더맨 뼈대에 맞춰 다시 구성했다. 원본 다운로드 파일은 보관하고, 새 클립은 가져온 fighting stance를 기반으로 한 파생 안무임을 메타데이터에 기록했다.

- 다리가 엇갈리는 공격 대신 일정한 앞뒤 스탠스와 낮춘 골반을 사용한다.
- 공격하지 않는 손은 얼굴 앞 가드를 유지한다.
- 왼손 잽은 짧은 직선, 오른손 스트레이트는 골반·몸통 회전, 왼손 훅은 옆으로 도는 궤적과 굽힌 팔꿈치, 강공격은 더 큰 준비·회전으로 구분한다.
- 공격마다 준비→빠른 타격→회수 곡선을 적용하고, 마지막 자세가 같은 가드로 돌아오게 했다.
- 발을 딛은 공격 중 캡슐을 강제로 전진시키던 보정을 제거했다. 이전에는 3타에 약 1.5m 이동하면서 미끄러졌고, 회피의 방향 이동은 유지한다.
- 공격 전환 블렌드를 180ms에서 55ms로 줄여 짧은 공격이 대기 자세와 섞여 흐려지는 문제를 줄였다. 타격 판정 시간은 기존 공격별 구간을 유지한다.

검증: npm test, npm run build 통과. 실제 리그 42개 경우와 4개 공격의 전방 궤적·반대 손 얼굴 가드·발 안정성·가드 복귀 회귀 검사 통과. 전체 37개 타임라인, 30/60/144 FPS 111개 경우, 15,262프레임 검사도 통과했다. 홍콩 지형·거미줄 기존 검사도 통과했다.

검토 화면은 실제 속도와 느린 속도, 최대 타격 자세 확인을 지원한다. 최근 동작 기록으로 콤보 순서를 확인할 수 있다. 실제 홍콩맵에도 동일한 컴파일된 모션을 사용한다. 화면과 실행 기록은 이 디렉터리에 보관한다. 최종 실제 홍콩 입력에서 IDLE/jab → IDLE/cross → IDLE/hook을 확인했고, 공격 전후 X/Z는 (0, 0)으로 유지되어 바닥 미끄러짐이 사라졌다 (`hong-kong-combo.json`).

수치 검사는 자세의 의미와 안정성을 확인하지만 미적 취향을 보증하지 않는다. 이번 변경은 기본 지상 전투 중심이며 회피·공중 내려찍기·피격은 기존 모션을 유지한다.
