# Mixamo 전투·이동 모션 선별 기록

## 적용 모션

| 게임 동작 | 원본 | 적용 기준 |
|---|---|---|
| 전투 대기 | `Boxing Idle.fbx` | 양손 가드, 반복 경계 연속성, 양발 접지 |
| 1타 잽 | `Lead Jab.fbx` | 30% 지점 타격, 반대손 가드, 종료 시 시작 자세 복귀 |
| 2타 스트레이트 | `Cross Punch.fbx` | 60% 지점 타격, 지지발 유지, 종료 시 시작 자세 복귀 |
| 3타 킥 | `Mma Kick.fbx` | 오른발 타격, 왼발 지지, 타격발 IK 해제, 종료 복귀 |
| 필살기 | `Surprise Uppercut.fbx` | 상승 궤적과 지지발을 보존한 0.67–1.77초 구간 |
| 공중 트릭 | `Front Flip.fbx` | 지상 준비·착지 부분을 제외한 0.50–1.43초 회전 구간 |
| 벽 기어가기 | `Climbing Up Wall.fbx` | 실제 수직 이동량으로 재생 속도 동기화, 벽면 깊이만 보정 |

## 제외 모션

| 후보 | 제외 이유 |
|---|---|
| `Jab Cross.fbx` | 하나의 콤보를 분할하면 잽 종료 시 팔이 가드로 돌아오지 않음 |
| `Stylish Flip.fbx` | 시작 프레임이 이미 공중이고 착지까지 포함해 공중 입력과 맞지 않음 |
| `Roundhouse Kick.fbx` | 종료 시 발과 몸 중심이 시작 자세로 복귀하지 않아 연속 공격에서 미끄러짐 |

제외 파일은 `docs/qa/mixamo-combat/candidates/`에 보관하고 실행 번들에서는 제거했다.

## 자동 검증 범위

- 실제 스파이더맨 리그에서 30/60/144 FPS 전투 자세의 유한값, 관절 정규화, 접지, 반복 입력 재시작 검사
- 잽·스트레이트·파워 스트레이트의 전진 궤적, 반대손 가드, 지지발, 종료 복귀 검사
- 킥의 타격 높이·방향·지지발·타격발 IK 해제·종료 복귀 검사
- 어퍼컷의 상승 궤적과 지지발 검사
- 각 원본 타격 프레임이 실제 게임 피해 판정 시간 안에 들어오는지 검사
- 39개 전체 모션을 30/60/144 FPS로 끝까지 표본화해 관절 길이, 순간 이동, 폭발 자세 검사
- 홍콩 타일 스트리밍과 충돌 환경 회귀 검사
