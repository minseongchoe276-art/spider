# 홍콩 맵 품질 개선 — 2026-10-29

목표: 기존 홍콩 지형과 이동·차량·전투를 유지하면서 깨져 보이는 원인을 재현하고 렌더링·근거리 표현·스트리밍을 개선한다. GTA와 동등한 완성도나 원본 데이터의 완전 복원을 약속하지 않는다.

## 순서와 완료 기준
1. **현황 분석/기준 화면**: 동일 시작점의 실제 외부 타일 로딩과 이동을 기록한다. 세 계층별 재질·텍스처·디테일 수준을 계측한다.
2. **안정적인 상세화**: 실제 화면 해상도에 맞는 세부 수준, 품질별 예산, 과도한 확대/반복 로딩 방지. 기존 부모 타일 보존과 충돌 교체 규칙 유지.
3. **재질과 조명**: 원본 사진/색상을 보존하고 무채색 대체 재질만 보완한다. 텍스처 필터링, 접지 그림자, 이동에 맞는 조명 범위를 점검한다.
4. **플레이 공간 품질**: 시작 지점과 근거리 표면을 분석하고, 근거 없이 실제 도로·건물을 가리거나 가짜 충돌 지형을 추가하지 않는다. 플레이 가능한 동선의 렌더링/충돌 일치 검증.
5. **검증**: 실제 홍콩 브라우저의 걷기·점프·카메라·와이어·차량 확인, 재질 WebGL 검증, 스트리밍/텍스처/카메라 회귀 검사와 프로덕션 빌드.
6. **전후 비교/한계**: 같은 시점 사진과 수치를 기록한다. 원본 지오메트리 결함과 별도 에셋 제작이 필요한 영역은 미해결로 명시한다.

## 기준 관찰
- 기존 버전의 실제 Chrome에서 시작 22.75초, 짧은 이동/점프 통과, 페이지/셰이더 오류 0.
- 초기 화면에서 늘어진 벽 텍스처, 세부가 적은 바닥과 겹쳐 보이는 구조, 낮은 표면 구분 확인.
- 기존 외벽 보정은 building 계층에 한정되어 해당 장면에서 적용 0. f2 지형 계층에 실제 건물 외관이 포함되므로 재질 구조 분석이 선행되어야 함.

이 문서는 실제 조사 결과에 따라 구현 항목과 검증 결과를 갱신한다. 원본 데이터/충돌 좌표/온라인 규칙은 임의로 변경하지 않는다.

## 최종 상태
- 현황 분석, 계층 표시 누락 수정, 품질별 상세도/캐시 안정화, 필터링/대체 외벽/환경 반사/이동 그림자 적용 완료.
- 주변 49개 지형 표본 분석과 실제 이동·스윙·차량 탑승/짧은 주행·카메라 검증 완료.
- 관련 회귀 검사, 실제 WebGL 검사, 빌드와 배포용 로컬 실행 확인 완료. 실험 중 근거리 지형을 악화시킨 거리 기반 상세도 완화는 제외하고 재검증함.
- 정밀 모델 교체, 거리 소품의 지역별 제작/배치, 손상된 수목 형상의 교체는 미구현. 원본 데이터의 한계와 다음 제작 순서는 REPORT.md에 구분함.
