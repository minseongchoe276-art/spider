# 전체화면·외형 변신·모션 검증 — 2026-10-19

## 적용 결과

**거미줄 모드 = 변신한 슈트 외형**, Q 1회 **전투 모드 = 사람 외형**, Q 재입력으로 기본 슈트 복귀. 원본을 실제로 렌더링해 확인했더니 업로드된 두 파일명과 외형이 반대로 붙어 있었다. `사람모습.glb`는 슈트 캐릭터였고 `변신모습.glb`는 검은 일상복 사람 캐릭터였다. 생성 매핑을 외형 기준으로 바로잡아 슈트가 거미줄 기본, 사람 외형이 전투 모드에서 나오게 했다. 모바일에서는 **더보기 → 변신** 버튼으로 동일하게 전환한다. 원본 파일의 텍스처와 외형은 그대로 유지했다.

두 원본은 스킨·뼈대·애니메이션이 없는 정적 GLB다. `scripts/build-appearances.mjs`가 기존 캐릭터의 65개 뼈대에 표면 가중치를 전이하고 역스키닝하여 `public/models/appearance-{web,combat}.glb`를 생성한다. 원본 파일은 수정하지 않는다. UV, 원래 인덱스 및 임베디드 텍스처를 보존하며 생성물에 원본 SHA-256을 기록했다. 초기 전이에서 손과 하의가 서로 끌리던 오류는 신체 영역을 구분하여 보정했다.

두 외형은 시작 전에 준비한다. Q 전환 중에는 네트워크 요청, 스켈레톤 교체, 믹서 재시작, 물리 위치·속도 변경을 하지 않는다. 같은 뼈대의 메시·재질만 바꾼다. 0.42초의 발광과 교차 링 효과를 적용하고 1인칭에서는 화면을 가리지 않도록 링을 숨긴다. 1인칭 팔은 선택한 외형에서 재생성한다. 온라인 아바타는 기존 combatStance 동기화를 사용한다.

## 브라우저에서 확인한 내용

실제 게임을 시작하고 Q를 눌러 거미줄 조작 버튼이 전투 공격 버튼으로 바뀌는 것을 확인했다. 다시 Q를 누르면 기본 외형과 거미줄 조작으로 복귀했다. 모션 검증 화면에서 기본 외형 대기·스윙과 전투 외형 잽·가드를 확인하고 증거를 저장했다. 34개 모두를 육안으로 완벽히 검수했다는 뜻은 아니며, 전 모션의 버텍스 검사는 자동화했다.

전체화면 버튼 진입·해제 및 진입 상태 라벨을 확인했다. PC 전체화면에서 캔버스와 뷰포트는 모두 1680×1050이었다. `desktop-game-fullscreen.png` 참조. 모바일 반응형 및 브라우저별 전체화면 처리는 기존 [전체화면·물리 보고서](../fullscreen-physics-2026-10-19/README.md)와 동일하다. 이번 IAB에서는 전체화면 이후 특정 배경 탭에 뷰포트 오버라이드가 적용되지 않아 그 탭을 390×844 실기기 검증 증거로 사용하지 않았다.

## 검증 범위와 한계

실제 iPhone·Android 기기에서 네이티브 전체화면 및 성능을 측정하지 않았다. 브라우저가 전체화면 API를 지원하지 않으면 홈 화면 웹 앱 실행 안내를 제공한다.

물리는 게임용 초인 이동 모델이다. 중력 28m/s², 점프·공중 제어·벽 이동 등의 게임 규칙이 있으므로 현실 물리의 완벽한 재현이라고 표현할 수 없다. 자동 점프·지면 미끄러짐·양손 거미줄 제약 오류를 수정하고 회귀 검사로 확인했다. 무동력 8초 스윙의 수치 에너지 손실은 약 1.209%다. 상세 수치와 다른 근사는 기존 물리 보고서에 있다.

생성 리깅은 자동 표면 전이이며 전문 수작업 웨이트 페인팅과 옷감 시뮬레이션을 대체하지 않는다. 극단적인 관절 자세의 옷 접힘·손가락 모양을 모든 시점에서 완벽히 보장하지 않는다.
