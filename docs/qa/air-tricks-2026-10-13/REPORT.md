# 공중 묘기 확장 — 2026-10-13

기존 앞구르기에 뒤구르기, 좌우 옆회전, 360도 회전, 코르크스크루를 추가했다. T는 앞구르기, W+T는 360도, S+T는 뒤구르기, A/D+T는 좌우 옆회전, Shift+T는 코르크스크루다. Shift가 방향보다 우선한다.

앞구르기는 기존 Front Flip 모션을 사용한다. 나머지는 기존 공중 자세에 몸통 중심의 회전을 더한 절차적 모션이다. 새로운 외부 모션 파일은 추가하지 않았다. 물리 위치·속도는 묘기에 의해 바뀌지 않는다. 줄을 놓은 자유 비행에서 실행하며, 착지 예상 시간에 여유가 필요하다. 동작 중 착지·벽 이동·줄 부착·집·초기화는 묘기를 중단한다. 완주한 묘기에만 점수가 주어진다.

한 번의 공중 이동에서 서로 다른 묘기를 연결하면 1.0~2.5배, 같은 묘기 반복은 1/2씩 감소(최저 1/8)한다. 착지와 초기화에서 연결 기록이 지워진다. 온라인 자세 데이터에 종류와 경과 시간을 추가했다. 온라인 다인 접속에서의 새 묘기 비교는 이번 확인 범위에 포함하지 않았다.

검증:
- `node scripts/check-air-tricks.mjs`: 6종 × 30/60/144 FPS, 완료 시 한 번만 점수 부여, 중단 시 무보상, 입력 선택, 반복 감점·종류 보너스, 위치/속도 보존, 초기화, 온라인 자세 필터 통과.
- `npm test`: 기존 전체 회귀 검사와 새 묘기 검사 통과.
- `npm run build`: 성공. 기존 큰 번들 경고는 남아 있다.
- `git diff --check`: 통과.
- 실제 Chrome의 절차 도시에서 혼자 플레이에 진입한 뒤 키보드 T, W+T, S+T, A+T, D+T, Shift+T 입력으로 각각 정확한 종류가 실행되는 것을 확인했다. 페이지 오류 0개. 입력 재현을 위해 테스트 페이지에서만 높이와 속도를 고정했다.
- 실제 캐릭터와 게임의 Character 모듈을 사용하는 별도 렌더에서 6종의 40% 진행 시점을 확인했다. 화면: [preview.png](preview.png). 렌더 페이지 오류 0개.
