# 홍콩 벽 오르기·맵 아래 추락 수정 — 2026-10-26

제보 화면의 난간이 있는 옥상 가장자리를 실제 Rapier 삼각형 지형으로 재현했다. 최초 검사에서 벽 오르기가 y=19.3에서 멈추는 문제, 시각 LOD 교체 중 붙잡은 벽이 제거되는 문제, 지형 아래 추락 후 최근 안전 위치로 복귀하지 못하는 문제가 모두 재현됐다(`before.log`).

## 수정

- 홍콩 벽의 가슴 높이에 난간 틈이 있어도 발 아래의 실제 벽과 옥상 지지를 함께 검사한다. 손이 상단 난간을 넘을 높이까지 오르며, 모든 진입 경로는 기존 캡슐 스윕·머리 공간·착지 지지 검사를 통과해야 한다. 로컬 도시의 막힌 가장자리 매달림 동작은 유지한다.
- 시각 타일이 사라져도 플레이어 주변 3m의 충돌 지형을 바로 제거하지 않는다. 벽에서 떠나면 기존 유예 시간 이후 정리한다. 마지막 안전 위치의 바닥은 별도로 유지하고, 동일 높이의 새 바닥이 준비되면 보호를 이전한다.
- 홍콩에서 안정적으로 서 있거나 걸을 때 바닥 9개 지점과 머리 공간을 확인하여 복귀 위치를 갱신한다. 추락 시 저장 위치를 다시 검증한 후 복귀한다. 일반적인 시작점 복귀 버튼은 기존 시작점을 사용한다.
- 홍콩의 지형 아래 추락 복구 높이를 -40m에서 -12m로 앞당겼다. 가상의 바닥을 추가하거나 장애물 충돌을 생략하지 않는다.

## 검증

- 새 회귀 검사 4개 그룹 통과. 난간 중앙·양쪽 모서리 × 24/30/60/144 FPS의 12개 도착 사례와, 입력을 놓은 뒤 지지 유지 확인 포함.
- 가까운 벽 LOD 보호와 이탈 후 정리, 마지막 안전 바닥 보존과 보호 해제, 최근 안전 위치로 추락 복귀 확인.
- 기존 벽·난간 검사 7개 그룹 통과. 실제 로컬 도시의 80개 벽면에서 79개 도착·1개 안전 매달림 확인.
- 기존 홍콩 스트리밍 어댑터 검사 9개 통과. 대체 지형 준비 중 원래 바닥 유지 및 준비 완료 후 이전 지형 정리 확인.
- 관련 로딩, 와이어 연속성, 이동 물리, 21개 이동·지형 사례, 14개 회복 사례 검사 통과.
- 추가 관절 리그·물리 불변식 검사 결과는 `wall-rig.log`, `physics.log`에 보관.
- 빌드·압축·릴리스 manifest 생성 결과는 `build.log`에 보관.

## 적용 범위

로컬 소스와 빌드 산출물에 반영했다. 운영 `minogame.site`의 배포 성공을 확인한 작업은 아니다. 확인 당시 운영 사이트는 다른 JS 파일을 제공했고 `/release.json`은 404였다. 실제 외부 홍콩 데이터의 모든 위치에서 플레이했다고 표현하지 않으며, 위 검사는 제보 형태를 재현한 실제 물리 지형과 기존 회귀 검사에 대한 결과다.
