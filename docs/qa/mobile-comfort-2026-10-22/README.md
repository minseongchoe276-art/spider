# 휴대폰 조작 개선 — 2026-10-22

- 기본 동작을 와이어·점프·집·회피·더보기로 정리. 와이어 84px, 점프 68px, 나머지 동작 60px. 작은 화면에서도 버튼을 축소하지 않음.
- 오른손 와이어·벽 이동·묘기와 시점 기능은 더보기에서 사용. 전투에서는 방어·강공격을 기본 화면에 표시.
- 스틱의 직선 방향 범위를 넓히고 중앙 데드존 확대. 질주는 외곽에서 시작하고 약간 돌아와도 유지하여 경계에서 반복 전환 방지.
- 동작 버튼 드래그는 최초 8px를 제외하고 카메라를 움직여 흔들림 완화. 감도 .0035 → .0028.
- 더보기 닫기는 메뉴에서 잡은 입력만 해제하며 이동 입력은 유지. 비활성 버튼 포인터 획득 방지. 회복 상태 안내 캐시 갱신 수정.

검증:
- `npm run test:touch`: 터치 회귀 검사 및 입력 수명주기 16개 통과. 직진, 질주 경계, 비활성 버튼, 최초 조준 드래그, 보조 메뉴 입력 해제 검사 포함.
- `node scripts/check-gameplay.mjs`: 프레임률별 물리·이동·점프·충돌 통과.
- `node scripts/check-reticle-only.mjs`: 조준점 기반 발사와 실패 시 운동량 보존 통과.
- `node node_modules/vite/bin/vite.js build`: 프로덕션 번들 생성 성공. 기존 대형 번들 경고 있음. 기존 모션 산출물을 다시 생성하지 않기 위해 Vite 빌드를 직접 실행.
- Chrome 모바일 에뮬레이션에서 실제 게임 혼자 플레이 시작 및 기본 조작 화면 확인: `portrait.png`.
- 실제 TouchControls와 프로젝트 CSS를 별도 게임 모형에 연결하여 320×568, 390×844, 430×932, 568×320, 667×375, 844×390에서 와이어/전투 × 더보기 열기/닫기 24개 배치 확인. 모든 버튼의 화면 내 위치, 버튼 간 비겹침, 최소 44px 터치 크기 통과: `layout-results.json`. 나머지 PNG는 이 배치 검사 화면이며 실제 3D 플레이 화면과 구분함.

실제 iOS/Android 하드웨어에서의 촉감·엄지 도달성은 확인하지 않았음.
