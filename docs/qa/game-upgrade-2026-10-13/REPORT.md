- 마지막 변경 후 추가 검사 통과: `upgrade-core.log`, `upgrade-online.log`, `remote-motion.log`, `minimap.log`. 저장 위치 복귀 시 레이스 무효화 및 옥상 진입 후 점수 확정을 포함한다.
- 실제 WebSocket 이동으로 목표 3개를 순서대로 완료하고 도망자 승리 확인. 실제 피격 확인 4회로 도망자를 쓰러뜨린 뒤 다른 도망자가 3초 가까이 머물면 HP 50으로 복귀하고 경기가 계속되는 것을 확인했다.

- 브라우저에서 카메라 설정·키 재배정·안전 위치 저장·복귀·혼합 전투 연습 시작/종료 확인: `browser-final.log`. 페이지 실행 오류가 없는지 확인한다.
- 두 브라우저 추격전 시작 및 역할 표시 확인: `online-two-player.png`.

## 데이터베이스 적용

연결된 Supabase 프로젝트에 `20261012234718_gameplay_experience.sql`과 `20261012235525_arena_correction.sql`을 적용했다. 충돌체·피격 확인 자료는 private game 스키마에 두고, 인증된 game_command RPC로만 동작한다. 직접 읽기 권한이 없음을 검사했다. 검사에서 생성한 임시 방은 정리했다. 웹사이트 배포나 Git 푸시는 수행하지 않았다.

## 검증의 한계

홍콩 공격 판정은 서버 거리·방향·쿨다운 검사와 피격자의 지형 확인을 조합한다. 홍콩 전체를 서버에서 물리 시뮬레이션하는 방식이나 완전한 부정행위 방지는 아니다. 이 작업은 전 세계 순위표, 모바일 터치 조작, 새로운 코스·도시 사건·튜토리얼을 추가하지 않는다. 성장·설정·고스트는 브라우저 로컬 저장이며 계정 간 클라우드 동기화가 아니다. 메달 기준과 적 전투 수치는 구현된 초기 밸런스이며, 여러 사람의 장시간 플레이를 통한 조정은 별도 검증이 필요하다. 모든 기기·환경에서 완전무결한 동작을 보증할 수는 없다.
