## 검증

- `npm test`: 전체 회귀 검사 통과. 움직임, 양손 줄, 진자 운동, 지형·벽 이동, 실제 리그 애니메이션, 전투, VFX, 미니맵, 원격 동작, 온라인 방, 재접속, 텍스처, 저장과 설정을 포함한다.
- `npm run test:audit`: 이번 수정의 14개 추가 회귀 시나리오 통과. 기본 전체 검사에도 포함했다.
- `npm run test:postgres`: 로컬 임시 PostgreSQL에서 16개 검사 통과. 2~8인 경기, 이동 예산, 서버 피격, 일시정지 중 피격, 비공개 테이블 권한, 트랜잭션 롤백 등 포함.
- `npm run build`: 최종 빌드 성공. 기존 번들 크기 안내 경고는 남아 있다.
- `git diff --check`: 통과.
- 기존 30/60/144FPS 장시간 혼합 이동 및 애니메이션 검사 유지. 새 결승 통과 시각도 같은 FPS들에서 0.5초로 일치한다.
- 추가로 방 입장·퇴장·준비, 만료된 참가 상태, 실시간 메시지 취소, 게임패드/키보드 실입력 검사 통과.

## 적용 범위

로컬 소스와 빌드 산출물에 적용했다. 이번 검증은 자동 검사와 로컬 DB를 중심으로 수행했으며, 이전 턴의 실제 2인 로컬 브라우저 검증과 구분한다. 외부 운영 사이트 배포 및 실제 물리 게임패드의 장치별 수동 플레이를 완료했다는 의미는 아니다. 모든 장치·지형에서 결함이 없음을 보증하지 않는다.

Supabase 변경 이력과 구독 API 문서를 확인했고, 이번 방송 필터 수정은 API나 DB 권한을 변경하지 않는다. 참고: https://supabase.com/changelog.md 및 https://supabase.com/docs/reference/javascript/subscribe .
