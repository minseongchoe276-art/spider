# HUD 및 카메라 회전 중 전투 검증 — 2026-10-26

## 판단과 변경

기존 HUD는 상단의 도시·혼자 플레이·자유 탐험·인원 배너, 모드 전환 알림, 하단 전투 준비 표시가 같은 내용을 반복했다. 체력과 기력은 긴 문장 안 숫자로 들어 있어 현재 상태를 빠르게 읽기 어려웠다.

- 상단의 전체 폭 배경·장식선을 없애고 도시 / 자유 탐험 / 지도와 우측 조작 버튼을 정렬했다. 혼자 플레이의 1명 표시는 제거했다.
- 체력과 기력을 이름·게이지·숫자를 가진 두 행으로 분리했다. 체력은 밝은 중립색, 기력은 금색이며 부족할 때 숫자와 체력 게이지가 경고색으로 바뀐다.
- 모드 전환 때 긴 배너를 띄우지 않는다. 현재 모드와 조작은 기존 HUD에서 확인한다. 전투 준비와 하단 모드 문구도 자원 HUD가 있을 때 중복 표시하지 않는다.
- 속도·고도는 시각적 비중을 낮췄다. 작은 화면의 미니맵은 좌표·범례·연결 배지를 줄여 글자 줄바꿈을 방지했다.
- 자원 수치는 DOM을 매 프레임 다시 만들지 않는다. 온라인 체력은 로컬 연습 체력이 아니라 현재 플레이어의 서버 갱신 값을 표시한다. 자원 HUD는 시뮬레이션 바깥에서 갱신하므로 일시정지·관전 중에도 낡은 체력 수치가 남지 않고, 탈락 시 관전 중으로 표시된다.

기존 전투는 공격 시작 때만 방향을 정하고, 이동 중에는 걷기/달리기 하체에 펀치 상체만 덧씌웠다. 가까운 적이 화면 밖에 있어도 그쪽을 바라보도록 되어 있었다.

- 공격 도중에도 카메라의 수평 조준 방향을 사용한다. 화면 밖 적을 향하는 자동 회전은 제거했다.
- 마우스·키보드 시점 입력을 카메라 렌더 업데이트까지 기다리지 않고 즉시 전투/이동 쪽에 전달한다.
- 지상 펀치는 원본 공격 클립의 골반과 다리까지 사용한다. 이동 방어 레이어가 펀치 상체를 다시 덮지 못하게 했다.
- 공격 동안 이동을 빠르게 제동하여 지지발을 확보한다. 질주→훅의 실제 제동 재현에서 뒷발이 바깥으로 기울던 경우는 제동 중 뒷발의 지지 위치를 기존보다 12cm 앞당겨 고쳤다. 초기 4cm 보정은 24FPS 재현에 통과했지만 60/144FPS에서 부족하여, 실패한 4개 조건 모두가 기존 허용치 25도에 통과하는 지지 위치로 조정했다. 정지 포즈의 지지 위치는 바꾸지 않았다. 공격 종료 뒤 누르고 있던 이동 입력은 자동으로 다시 적용된다. 계속 전속력으로 달리며 펀치하는 방식에서 발을 디디고 치는 방식으로 바뀌었다.
- 구르기 복귀·방어·회피는 각자의 기존 처리 경로를 유지한다.

## 재현 가능한 검증

각 로그와 steering.json이 이 폴더에 있다. 기존 리그·발·스킨 검사의 상세 수치는 각 스크립트가 원래 사용하던 QA 폴더에도 기록된다.

| 검사 | 확인 대상 |
|---|---|
| check-combat.mjs | 공격 가능 상태, 피해 시점, 벽·높이·후방 배제, 방어·기력·취소 |
| check-combat-aim.mjs | 조준 표시/입력 일치, 시점 입력 즉시 전달, 키보드 시점 회전 |
| check-strike-steering.mjs | 24/60/144FPS × 잽/스트레이트/훅/강공격/특수 × 정지/옆 질주, 카메라 회전 및 ±π 경계, 판정 방향과 몸 회전, 직선 펀치의 실제 주먹 중앙 위치 |
| check-combat-quality.mjs | 24개 품질 사례, 전신 클립 사용, 타격 순간 제동, 이동 복귀, 손 연속성, 관절 범위 |

이전 검사의 ‘공격 중에도 계속 3m/s 이상 이동’ 및 ‘공격 중 보행 클립이어야 함’ 조건은 새 발 디딤 정책과 반대였다. 해당 조건은 발을 디딘 공격 클립 사용, 타격 순간 이동 속도 제한, 공격 뒤 입력 복귀를 확인하도록 바꿨다. 관절·피해·접지 허용치는 완화하지 않았다.

회전 검사 실측: 판정 방향 오차는 부동소수점 오차 수준(최대 약 1.4×10⁻¹⁴도), 안정화 후 몸 회전 지연은 최대 3.59도였다. 직선 펀치 18개 타격 표본의 중앙선 이탈은 최대 0.146m, 전방 뻗음은 최소 0.712m, 타격 중 수평 이동 속도는 최대 0.068m/s였다. 이 값은 이 검사의 150도/초 회전 조건에 해당하며 모든 마우스 입력 속도에 대한 보증은 아니다.

발 접지 검사의 기존 고정 속도 조건은 공격 중에도 모델을 계속 4.4/6.5m/s로 강제 이동시켰다. 실제 컨트롤러와 동일한 감쇠율(공격 중 32, 복귀 중 9)을 반영한 연속 동작 검사를 별도로 실행했다. 정지 포즈 75개는 전체 리그 실행에서 검증한 기록을 held-feet.json에 보존했고 held-feet.log에서 다시 확인했다. --continuous-only 옵션은 변경된 연속 동작 조건만 재검사하기 위한 옵션이며 접지·관절 허용치를 바꾸지 않는다.

## 검증 범위

로컬 코드와 로컬 홍콩/네온 도심 화면, 실제 모델을 사용하는 자동 검사다. minogame.site에 배포하지 않았으며, 이번 변경 후 실제 다인 온라인 대전과 모든 실물 기기에서의 플레이 감각을 검증한 것은 아니다. 자연스러움은 수치 검사만으로 완전히 보장할 수 없으므로 ‘모든 환경에서 완벽’이라고 판정하지 않는다.
