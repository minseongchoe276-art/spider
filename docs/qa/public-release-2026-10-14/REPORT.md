# 운영 버전 재검수 — 2026-10-14

현재 배포한 버전의 재검수는 통과했다. 모든 미래 상황의 무결함 보증은 아니다. 소스 스냅샷은 `0385cef`, 게임 실행 코드와 Render 서버는 `eec22d6`이며 이후 커밋 차이는 검수 문서다. 공유 작업 폴더에서 진행 중인 미커밋 수정은 포함하지 않았다.

- 격리한 커밋 소스에서 `npm test` 34단계와 `npm run build` 성공. 실제 모델 모션·전환, 양손 거미줄, 실제 Rapier 충돌, 온라인 규칙, 축소 도시와 서버 지형 일치 검사를 포함한다. [테스트](tests.log), [빌드](build.log). 기존 큰 번들 경고는 남는다.
- 운영 사이트 JS SHA-256은 이번 격리 빌드와 정확히 일치한다. Render의 최신 배포도 같은 도시 실행 코드를 사용한다. 서버 상태는 ready, 공식 지형 준비는 CLEAR다. [배포 대조](deployment.json).
- 실제 공개 서버에 임시 참가자 8명을 연결해 정상 피해, 공식 홍콩 지도 벽 차단, 피해자의 위조 확인 무시, 탈락 상태 재접속과 검사 방 정리를 재검증했다. 공격 왕복 표본은 약 124.8~130.9ms다. 기존 방은 변경하지 않았다. [공개 서버 결과](public-results.json), [로그](public-server.log). [이전 결과](previous-public-results.json)를 별도로 보존했다.
- 실제 운영 브라우저에서 Space→T→착지 후 W 이동을 실행했다. 묘기 점수 250과 착지 성공 안내를 확인했고 동쪽 위치가 −100m에서 −85m로 변했다. Q 전환 후 좌·우 공격 입력과 W 이동은 −85m→−83m, COMBAT READY로 복귀했다. 이 검사는 지상 공격 입력과 복귀를 확인한 것이며, 양손 공중 스윙 전체 경로는 자동 물리 검사와 이전 검수 범위다.
- 조준점은 두 측정 모두 1280×720 화면의 중앙 (640,360), 28×28px였다. 미니맵은 정상 `180m`로 표시됐다. 과거 캡처의 `0m` 표시는 최신 운영 버전에서 재현되지 않았다. 브라우저 error/warn 표본은 없었다. [브라우저 기록](browser.json), [실제 화면](production-motion.png). 검수 후 로비로 돌아가고 임시 탭을 닫았다.

무료 서버의 유휴 복구와 재시작 시 메모리 방 소멸 제한은 유지된다. 유료 서버나 결제를 추가하지 않았다. 이번 통과는 위 운영 버전과 명시한 검사 범위에 한정하며, 최신 미커밋 변경의 배포 또는 신선한 Supabase 전체 합격 검사로 해석하지 않는다.
