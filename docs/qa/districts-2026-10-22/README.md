# 로컬 맵·스킬 연출·영어판 검수 (2026-10-22)

## 구성

홍콩은 유지하고 로컬 맵 5개를 제공합니다. 추천 코스는 **스카이 가든 → 네온 도심 → 선셋 항만 → 브릭 구시가지 → 크라운 금융가**입니다. 코스는 각 맵의 선택 순서이며, 지도가 하나의 연속된 월드로 합쳐지는 기능은 아닙니다.

| 맵 | 플레이 목적 | 구성 |
|---|---|---|
| 스카이 가든 / Sky Gardens | 입문·탐험 | 중저층, 옥상 녹지, 주변 화단, 완만한 높이 변화 |
| 네온 도심 / Neon Core | 기본 추천·균형 | 기존 온라인 충돌 구조를 유지한 중고층, 보도, 발광 외벽 |
| 선셋 항만 / Sunset Harbor | 넓은 시야·여유로운 이동 | 낮은 창고, 넓은 도로, 부두 컨테이너, 외곽 수면과 석양색 하늘 |
| 브릭 구시가지 / Brick Quarter | 근접 전투·벽 이동 | 넓은 건물 발자국, 좁은 골목, 벽돌 외벽, 거리 표식 |
| 크라운 금융가 / Crown Skyline | 숙련·수직 스윙 | 높은 타워, 발광 수직선, 차가운 유리 외벽 |

로비, 로딩 화면, 일시정지 메뉴와 M 전체 지도에서 선택할 수 있습니다. 미니맵과 전체 지도는 현재 도시의 실제 건물·지형과 플레이어 위치를 재사용합니다. 위치 저장과 탐험 기록은 맵 ID별로 구분합니다. 지도 변경은 새 지도의 로비로 이동합니다.

**온라인 범위:** 새 로컬 변형 맵은 솔로 탐험용입니다. 해당 맵에서 방 생성·참가를 누르면 요청과 언어를 유지해 네온 도심으로 이동합니다. 기존 홍콩 온라인 플레이는 유지됩니다. 변경된 로컬 지형을 기존 서버 충돌 데이터로 잘못 판정하는 상황을 막습니다.

## 화면·언어

스킬 시전은 확정된 입력 동작을 관찰해 원형 문양, 동작명, 캐릭터 주변의 곡선 에너지 궤적을 표시합니다. 시전 표시 중 일반 안내와 전투 상태 표시의 겹침을 줄였습니다. 발동·시전과 명중·피해 확정은 구분하며, 전투 수치나 쿨다운을 변경하지 않습니다. 재사용하는 이펙트 풀 6개로 개수를 제한합니다. 효과 줄이기를 켜면 3D 궤적과 타이틀 애니메이션을 줄이고 이름은 확인할 수 있습니다.

한국어/EN은 로비와 일시정지 메뉴에서 전환합니다. URL의 lang 값이 우선하며 선택을 저장합니다. 메뉴, 설정, 조작 안내, 게임 메시지, 위치·전투 정보와 접근성 문구에 영어 문구를 제공합니다. 플레이어·방 이름 입력값은 유지합니다.

## 검수 기준

'44년 경력'을 실제 경력으로 주장하지 않고, 숙련 게임 개발 검수의 관점으로 아래 분야를 점검했습니다.

- 레벨 디자인: 5개 고유한 생성 시드와 지형, 도로 폭·높이·외형의 역할 구분.
- 이동·물리: 충돌·벽 이동·와이어·착지·카메라 관련 회귀 검사.
- 시작·저장: 총 47개 옥상 시작 후보에서 몸통 충돌 없음. 각 맵에 바닥이 있는 시작점 확인. 저장과 탐험 기록을 맵별로 다시 읽기.
- 전투·모션: 기존 공격 판정·모션·온라인 동기화 검사를 실행. 시각 효과가 피해를 확정하지 않는 구조 유지.
- 지도: 현재 맵 식별, 실제 지형 재사용, 위치 좌표 투영, 전체 지도 이동 링크 확인.
- UI·모바일: 실제 약 319px 폭 화면에서 로비·게임·전체 지도·일시정지·스킬 표시 확인. 발견한 스킬 줄바꿈과 안내문 겹침 수정.
- 영어: 563개 번역 항목, 수치가 들어가는 메시지, 접근성 라벨, 언어 왕복 전환과 지도 변경 후 유지 검사.
- 네트워크: 개발용 로컬 서버에서 항만 → 네온 도심 자동 이동 후 방 이름·모드 유지 확인. 검증용 방은 나가기 처리.
- 성능·리소스: 맵별 213~281개 메시, 184~238개 충돌체. 생성 메시 개수의 상한과 결정성 확인. 스킬 이펙트는 풀을 재사용.
- 빌드·회귀: maps.json, targeted.json, full-audit/ 및 최종 검증 결과 파일 참조.

실기기 전 기종, 장시간 발열·배터리, 인터넷 지연별 8인 실전 부하, 실제 사용자 주관 평가까지 완료했다는 의미는 아닙니다. 빌드에는 기존 대형 JS 청크에 대한 Vite 경고가 남아 있습니다. 자동 검사와 브라우저 확인으로 검증한 범위를 구분합니다.

## 최종 결과

기존 회귀 검사 **96/96 통과**, 최종 UI 변경의 영향을 받는 검사와 신규 검사를 합친 **29/29 재검사 통과**, 최종 빌드 통과입니다. 별도 스킬 풀·온라인 시전·실제 브라우저 검사도 통과했습니다.

전체 검사 원본은 실행 도중 7개 UI/언어 파일이 보완되어 소스 불변성 상태를 FAIL로 기록했습니다(개별 검사 실패는 0개). 이를 숨기지 않고 보관했으며, 해당 파일을 가져오거나 소스 검사로 읽는 모든 검사 묶음을 최종 소스에서 다시 실행했습니다. 최종 소스 해시 불변성과 영향을 받지 않은 파일의 동일성까지 확인한 합산 결과는 final-summary.json의 PASS입니다.
