# 거미줄 연결 유지 수정 — 2026-10-13

## 원인 및 수정

- 이전 스윙은 시각 지형 LOD가 바뀌어 부착면 충돌체가 제거되거나, 부착면 탐색이 한 틱 실패하면 바로 줄을 해제했다. 연결 당시 확인한 실제 충돌체를 두 손의 줄이 사용하는 동안 유지한다. 줄 해제·위치 초기화·서버 위치 보정 시 보존을 해제한다.
- 실제 충돌체 재생성 중 부착면 판정이 사라지는 경우 최대 0.35초의 재확인 시간을 둔다. 실제 중간 벽은 즉시 감지하고, 영구히 사라진 부착면은 해제한다.
- 거미줄 끝에서 1.5m 이내의 동일 방향 표면 이음매는 경로 차단으로 취급하지 않는다. 원점 안쪽 판정의 오탐을 줄이기 위해 비실체 표면 레이를 사용한다.
- 바닥이나 옥상을 스칠 때 누르고 있는 줄과 높은 부착점을 유지하고, 같은 축을 사용하여 점프 궤적으로 복귀한다. 줄 길이를 순간적으로 줄여 플레이어를 순간 이동시키지 않는다.
- 자동 해제 시 실제 눌린 마우스 입력을 지우지 않는다. 부착점을 잃었다가 장애물이 사라지면 누르고 있는 손만 재연결을 시도한다. 정상 연결 중에는 축을 바꾸거나 다시 쏘지 않는다. 실제 마우스 해제는 즉시 반영한다.
- 함께 진행된 기존 점프·공중 발사·진자·입력 복구 개선을 유지했다. 이전 QA 기록의 단계별 동작 설명보다 현재 코드와 이번 최종 검사 결과를 우선한다.

## 재현 검증

`npm run test:web-continuity`의 8개 결과:

1. 30FPS, 8초 진자 왕복 중 0.2초 부착면 소실에도 원래 축과 줄 유지. 영구 부착면 소실은 해제.
2. 60FPS의 동일 시나리오 통과.
3. 144FPS의 동일 시나리오 통과.
4. 부착점 이음매를 허용하면서 실제 중간 벽은 차단.
5. 실제 눌린 손은 장애물 제거 뒤 재연결, 마우스를 놓으면 즉시 해제.
6. 실제 GameApp 렌더링 루프에서 자동 해제 후 누른 입력이 보존됨.
7. 내려오며 지면을 스쳐도 축 유지, 같은 부착점으로 공중 스윙 복귀.
8. 실제 Rapier 삼각형/캡슐에서 8초 진자 왕복 동안 시각 LOD 제거에 살아 있는 부착 충돌체 유지. 마지막 줄을 놓으면 보존 충돌체 해제/제거.

기존 진자 에너지/고정 길이/관성 해제, 양손 소유권, 실제 장애물 차단, 스트리밍 지형 및 기본 플레이 회귀 검사를 함께 실행했다. 전체 로그는 full-tests.log, 빌드는 build.log에 기록한다.

## 범위

로컬 소스와 실제 물리 엔진으로 검증했다. 모든 운영 지형과 장치에 대한 무결함 보증은 하지 않는다. 실제 벽 차단·마우스 해제·모드 전환·서버 보정처럼 의도된 해제는 유지한다. 커밋 및 원격 푸시 결과는 대화에서 별도로 보고한다.

최종 `npm test`, `npm run test:web-continuity`, `npm run build`, `git diff --check` 모두 통과했다. 빌드의 기존 번들 크기 경고는 남아 있다.
