# 게임 선택 화면 단순화

- 첫 화면은 현재 지도, 혼자 플레이, 함께 플레이 중심으로 구성했습니다.
- 지도 목록은 '지도 변경'을 눌렀을 때만 이름 중심으로 펼칩니다. 맵 선택 자체로 페이지를 다시 불러오지 않으며, 플레이를 눌렀을 때 선택한 도시로 이동해 바로 시작합니다.
- 온라인 참가·방 목록은 별도 화면으로 분리했습니다. 모드, 정원 등 생성 옵션은 '방 만들기' 안에 모았습니다.
- 긴 추천 코스와 중복 설명, 과도한 제목·장식·순번을 첫 화면에서 덜어냈습니다.
- 로딩 화면의 지도 목록도 필요할 때만 펼칩니다. 한국어와 영어 화면 모두 반영했습니다.

검증: 기존 세션 흐름, 게임 모드, 입력 수명주기, 관리자 화면, 지도·언어 검사 5개 묶음 통과 및 프로덕션 빌드 통과. 실제 브라우저에서 모바일 폭과 넓은 화면을 확인했습니다. 지도 선택 시 URL 유지, 플레이 확정 시 선택 도시로 이동하고 자동 진입, 온라인 화면 이동·복귀, 방 생성 옵션 펼치기와 한영 전환을 확인했습니다. 기존 대형 JS 청크 경고는 유지됩니다.
