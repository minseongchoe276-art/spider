# 모션 자연스러움 개선 · 2026-10-11

후속 구현으로 옥상 넘기기와 경사면·계단 발/골반 보정을 추가했다.
아래 내용은 첫 검토 기록이며 최신 구현과 검증 범위는
[지형·옥상 추가 검증](TERRAIN_MANTLE_2026-10-11.md)을 참조한다.

## 판정

현재 캐릭터에 맞춘 자세 보정과 동작 전환을 적용했다. 자동 검증과 실제 브라우저의
대표 장면 시각 검사를 통과했다. 모든 프레임·지형·입력 조합에서 실제 사람과 동일하거나
완벽하다는 판정은 아니다. 전용 촬영 모션이 없는 상태를 관절 보정으로 개선한 부분이 있다.

## 적용한 변경

- 걷기·조깅·달리기·질주: 실제 타깃 리그의 발 높이를 샘플링해 접지 구간을 추출했다.
  지지면이 있는 접지 구간에만 발을 고정하고, 실제 이동 속도로 재생 속도를 조절한다.
  발목 기준 지면 여유를 11cm로 맞춰 기존의 발 침하를 수정했다.
- 접지 해제: 발을 떼는 순간 IK 보정을 바로 제거하면 한 프레임 최대 74cm가 튀는 문제가
  추가 측정에서 발견됐다. 보정의 감쇠와 발 목표 이동량 제한을 추가했다.
  144fps 걷기 검사에서 최대 프레임 이동량은 약 744mm에서 92mm로 감소했다.
  이는 순간 이동 완화 수치이며 실제 보행의 완벽한 속도·궤적 인증은 아니다.
- 정지: 여성 정지 원본을 일반 정지에 사용하지 않는다. Run To Stop의 안정된 마지막
  8프레임을 느린 정지에 사용하고 질주 정지는 전체 클립을 사용한다.
  원본 Female Stop Walking은 `femaleStop` 비교 클립으로 보존했다.
- 벽 이동: 일반 달리기 대신 중립 자세에 대각선 교대 손·발 IK를 적용했다.
  좌우 목표가 몸을 가로지르던 오류, 손바닥·발바닥 방향, 누워 있던 몸 축을 수정했다.
  옥상 모서리에서 벽 탐색이 먼저 끊겨 떨어지는 문제와 진입 후 180도 방향 전환도 수정했다.
- 웹 집: 점프 클립 대신 당기기용 파생 자세를 사용한다. 속도 방향을 향하는 상체,
  뒤로 접는 다리와 앵커를 향하는 양팔을 적용한다. 발사·해제 시 팔 보정은 부드럽게 전환한다.
  유지 입력이 웹 집을 첫 프레임부터 일반 스윙으로 덮어쓰던 컨트롤러 분기도 수정했다.
- 검증 화면: 실제 벽·웹 집 장애물의 충돌 형상을 연결하고, 높은 낙하의 구르기 조건과
  벽 이동 입력을 수정했다. 검증 UI는 시간 지정으로 동일 장면을 재현할 수 있다.

## 검증 근거

최종 `npm test`와 `npm run build` 모두 종료 코드 0.

- 23개 컴파일 클립, 65개 타깃 뼈: 원본·리타게팅·직렬화·루프·유한값 검사.
  23개는 18개 원본 FBX에서 파생한 클립을 포함하며 새로 촬영한 23개 모션이 아니다.
- 실제 타깃 리그 자세 검사 36개: 30/60/144fps 시간 간격에서 4종 보행,
  실제 지면의 대기 자세, 3방향 벽면, 3방향 웹 집, 정지 복귀 검사.
  고정된 발의 접지 중 이동은 출력 정밀도에서 0.0mm였고 벽의 접지 목표 오차는 2cm 미만이었다.
  발 해제 구간의 프레임 이동량도 검사한다. 이는 CPU 자세 계산이며 GPU의 실측 FPS 검사는 아니다.
- 컨트롤러·게임플레이 검사: 연속 발사/재부착, 당기기 후 연결, 옥상 진입,
  낙하·착지·구르기·묘기 복귀, 충돌·카메라·여러 시간 간격.
- 기존 QA 34개 및 2차 검토 11개 통과. 장시간 혼합 이동 검사는 12분의 시뮬레이션 시간이다.
- 브라우저: 23개 클립의 중간 자세와 8개 연결 시나리오의 대표 시점을 확인했다.
  최종 걷기·정지 화면 및 오류 로그도 확인했다. 확인 시 오류 목록은 비어 있었다.
  모든 프레임을 연속 시청하거나 홍콩 지도 전체를 검사한 것은 아니다.
- 실제 로컬 도시 게임도 시작해 입력 없는 옥상 대기 화면을 확인했다.
  확인 시 HUD 속도는 0km/h였으며 오류 목록은 비어 있었다. 이 시작 점검은 전체 실플레이를 대신하지 않는다.
- 빌드는 통과했으나 약 5.26MB 주 번들에 대한 크기 경고는 남아 있다.

## 남은 자연스러움 작업

1. 벽 이동·웹 집·옥상 넘기기 전용 애니메이션을 확보해 실제 리그에서 조정해야 한다.
   현재 벽 이동은 절차적 교대 IK이며 옥상 진입은 물리 전환으로, 손으로 짚어 넘는 전용 모션은 없다.
2. 경사면·불규칙 지면의 법선 기반 발 회전, 뒤꿈치→앞꿈치 구르기,
   골반 높이 보정까지 구현한 완전한 지형 적응 IK는 아니다.
3. 벽 모서리·타일 로딩/교체·홍콩의 모든 도로와 건물·입력 조합은 별도 실플레이 검증이 필요하다.
4. 공중 묘기는 기존 절차적 몸 회전을 포함한다. 다양한 전용 스파이더맨 묘기 클립은 별도 제작 대상이다.
5. 빠른 속도 변화·급회전의 모든 구간에서 보행 위상과 관성까지 생체역학적으로 맞춘
   모션 매칭 시스템은 아니다. 30fps에서 검사한 빠른 발 회복 이동량도 추가 시각 튜닝 여지가 있다.

새로고침 후 `/?motionReview`의 동작 연결 메뉴에서 최종 장면을 직접 확인할 수 있다.
