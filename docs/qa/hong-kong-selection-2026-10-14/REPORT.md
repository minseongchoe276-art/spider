# 홍콩 지도 선택 복구

로컬 도시 주소 `?city=procedural`로 접속하면 홍콩 전환 링크는 일시정지 화면 맨 아래에만 있었다. 시작 로비의 혼자 플레이 바로 위에 홍콩/로컬 도시 선택 링크를 추가했다. 선택한 지도는 강조 표시하며 시작 버튼에도 표시한다. 초기 로딩 중에도 지도 선택을 제공한다. 기본 홍콩 및 기존 지도 프록시는 유지한다.

공개 수정 커밋: `cd353f8`. 기존 미커밋 작업과 분리한 HEAD 기준 체크아웃에서 UI 변경 네 파일만 공개 main에 반영했다.

검증:
- 분리한 공개 코드의 프로덕션 빌드 통과.
- 지도 선택 기본값, 명시적 홍콩/로컬 선택, 잘못된 파라미터 처리, 현재 지도 표시 검사 통과.
- 기존 홍콩 지형/이동 8개 시나리오 및 세션 흐름 12개 시나리오 통과(작업 폴더 기준).
- Chrome에서 로컬 로비의 홍콩 링크 클릭 후 홍콩 URL, 지도 로딩 및 시작 버튼 지도명 확인.
- Vercel 공개 배포 성공: https://vercel.com/ms-projects14/spider/AQve6474DrADJxf1Emy8s8vcH7Ju
- 실제 공개 로컬 로비에 지도 선택 표시 확인(`public-map-picker.png`). 공개 홍콩 링크 클릭 후 `?city=hong-kong` 및 홍콩 로딩 확인.
- 로컬 새 홍콩 세션은 실제 지형 파싱 후 LIVE 준비 완료. 첫 지형 로딩은 30초 지연 안내가 뜬 뒤에도 계속 진행되어 정상 완료됨.
- 공개 홍콩도 LIVE 준비 완료, 브라우저 오류 로그 없음. 혼자 플레이로 진입 후 W 입력으로 미니맵 좌표가 동쪽 0m/북쪽 2m에서 동쪽 -1m/북쪽 3m로 변경됨. 실행 증거: `public-hong-kong-play.png`.
- 테스트 브라우저에서 기본 품질 약 9 FPS 관측. 이번 수정은 지도 선택 접근성을 복구하며 성능 최적화를 포함하지 않음.
