# SHADOW PULSE 우선순위 개선 및 검증

기준일: 2026-10-28 · 대상: 현재 로컬 작업 트리와 프로덕션 빌드.

게임의 입력·전투 수치·원본 모션·기존 저장 기록을 유지하면서, 온라인 판정부터 모션·목표·화면·음향·성능·배포 경로까지 개선했다. 기존 차량 작업은 보존하고 차량과 연결되는 UI·임무·음향을 보강했다. 운영 서비스 배포와 운영 DB 변경은 이 보고서의 범위에 포함되지 않는다.

## 실제 플레이와 검증 결과

- 데스크톱 Chrome 브라우저 13개 항목 통과, 처리되지 않은 오류 0개.
- 500m 순찰은 임무 시작 후 위치를 바꾸는 프로브 없이 W/S와 Shift만으로 완료했다. 실제 경과 약 48.1초, 게임 기록 46초, 800점 은메달. 초기 준비 위치만 시험용으로 배치했다.
- 옥상 3곳 도착 검사는 재현용 위치 배치 후 실제 지지·착지·체류 판정을 사용했다. 이를 사람이 자연스럽게 세 옥상을 플레이한 결과로 확대하지 않는다.
- 모바일은 Chrome 터치 에뮬레이션에서 실제 터치 포인터 드래그·이동+점프 동시 입력·취소·화면 회전·메뉴 5개 항목 통과.
- 로컬 4인 Chrome에서 호스트 위치를 본 다른 세 클라이언트의 수평 오차는 각각 약 0.005m. 재접속 결과도 기록했다. 서로 다른 인터넷 회선의 네 사람 시험은 아니다.
- 8개 실제 소켓의 서버 반복 접속 시험은 120초 통과. 30분 또는 GPU/모바일 시험으로 표기하지 않는다.
- 기존 `npm test`의 90개 명령은 처음 23개와 나머지 67개를 분할 실행했다. 초기 실패는 수정 또는 현재 모션 계약에 맞춘 검증 정리 후 재실행했다. 최종 결과는 `final-validation.json`에 병합했고 초기 실패 로그는 보존했다.
- 첫 실패에는 새 시작 시점의 간소화된 객체 처리, 예전 펀치 소스/어퍼컷 계약을 요구한 검사, 실제 발·몸통 문제 및 수정 도중의 구문 오류가 포함된다. 구문 오류는 수정 후 빌드·관련 검사를 다시 통과했다. 최초 `npm test` 프로세스가 한 번에 성공했다고 보고하지 않는다.
- 빌드 예산 세 항목 통과. 실제 HTTP 전체 파일·상태·식별 검사 133개 통과. 검증 전후 소스 지문 일치.

## 남는 외부 검증 범위

실제 iOS Safari·Android Chrome·목표 저사양 기기의 장시간 발열·배터리·입력·메모리 시험, 신규 사용자의 이해도와 재방문, 사람이 듣는 음질·믹스 평가는 이 환경에서 완료하지 않았다. 자동 검사로 재미와 상용 완성도를 수치화하지 않았다.

홍콩 데이터는 원래 사진 지면·저해상도/무채색 표면의 품질 한계가 있다. 건물용 재질 보정은 해당 조건의 데이터가 들어올 때만 적용한다. 이번 홍콩 시작 관측에서는 별도 building 계층의 대상 메시가 0개였으며, 모든 회색 면을 바꿨다고 보고하지 않는다. 보정 자체는 별도의 실제 WebGL 렌더 검사로 검증했다.

제공된 일부 캐릭터·모션 등의 출처 증빙은 기존 `needs-review` 상태를 유지했다. 출처·권리를 추정해 승인 처리하지 않았다. 운영 배포·운영 DB 상태는 로컬 빌드 검증과 별개의 확인 대상이다.
