# 지형 적응·옥상 넘기기 추가 구현 — 2026-10-11

## 결과

기존 자연스러움 검토에서 남았던 옥상 넘기기와 경사면 발·골반 보정을 구현했다.
새로 촬영한 FBX를 추가한 것은 아니다. 기존 타깃 리그와 모션 위에 절차적 자세를 적용했다.
최종 코드로 자동 검사, 빌드 및 실제 캐릭터의 대표 화면을 확인했다.
이는 검사한 조건의 통과이며 모든 지도·프레임·입력 조합에서 실제 사람과 같다는 보증은 아니다.

## 구현

### 옥상

- `MANTLING` 상태: 0.72초 동안 손 짚기 → 캡슐 올리기 → 발 올리기 → 일어나기를 연결한다.
  첫 프레임에 옥상 안쪽으로 위치를 옮기지 않는다.
- 손목은 실제 난간 좌표에 맞추고, 몸을 낮춰 팔의 도달 범위를 확보한다.
  손 지지를 풀면서 골반을 올리고 다리를 옥상 위에 놓는다.
- 절차 도시와 스트리밍 캡슐의 벽 간격을 같은 값으로 가정하지 않는다.
  실제 벽까지의 거리를 질의해 난간 위치, 몸 오프셋, 손·발 목표를 설정한다.
- 몸의 충돌 형상을 먼저 위로 올린 뒤 수평 이동한다. 이동 경로와 천장 여유를 검사하고
  도중에 새 장애물이 나타나면 중단한다. 절차 도시와 실제 삼각형 충돌을 모두 사용한다.
- 착지 면의 중앙뿐 아니라 9개 지점을 검사한다. 좁은 난간·없는 타일·급격한 지면 변화는 거부한다.
  진입 도중에도 착지 범위를 재검사해 타일 교체로 가장자리가 사라지는 경우 중단한다.
- Space로 중단·점프, 거미줄 발사/당기기로 전환할 수 있다. 초기화 시 진행 중인 자세와 접지 캐시도 해제한다.

### 경사면·계단

- 충돌 월드의 지면 질의가 높이와 법선을 함께 반환한다. 발별 지면 높이와 법선을
  사용해 이동 중 접지와 대기 자세의 발바닥을 보정한다.
- 골반 높이를 최대 22cm 낮추고 보간한다. 지지면이 없거나 걸을 수 없는 법선이면 발을 고정하지 않는다.
- 계단에서는 발 앞쪽의 높이 변화도 확인해 공중 발의 발끝이 단차를 넘기 전에 올라가게 한다.
  일반 경사의 예상 높이와 비교하므로 경사면을 계단으로 오인하지 않는다.
- 지지 타일의 작은 높이·법선 변화는 보간하고, 큰 높이 변화는 접지를 해제한다.
- 오르막에서 매 물리 틱마다 수직 속도를 0으로 만들던 동작을 지면 접선 이동으로 수정했다.
  충돌 제어기가 확보한 피부 여유 높이를 다시 지면 +10cm로 내리던 동작도 수정했다.
- 계단 자동 오르기의 접촉을 실제로 막힌 벽 접촉과 구분한다. 캡슐의 앞쪽 지지까지 확인해
  중앙 지점이 아직 낮은 바닥 위에 있을 때 성공한 계단 오르기를 낙하로 취소하지 않는다.

## 최종 검증

- `npm test`: 종료 코드 0.
- `npm run build`: 종료 코드 0. 약 5.26MB 주 번들 크기 경고는 남아 있다.
- 실제 리그 자세 검사 총 63개: 기존 36개 + 경사/옥상 18개 + 실제 캡슐·리그 결합 경사/계단 6개
  + 실제 삼각형 벽 간격을 사용하는 옥상 자세 3개.
  30/60/144fps의 시간 간격을 사용했다. GPU 실측 성능이나 모든 프레임의 시각 검사와는 구분한다.
- 손 지지 구간의 난간 목표 오차 최대 14.8mm. 발을 올린 후 발목과 무릎이 지붕 아래로 들어가지 않는지도 검사한다.
- 실제 캡슐·리그 경사/계단 검사에서 접지 구간의 발목 높이 오차는 로그 정밀도상 0.0mm였다.
  접지하지 않는 구간 전체가 무오차라는 뜻은 아니다.
- 추가 물리 예외 검사 21개: 프레임 독립성, 천장, 좁은 착지 면, 잘못된 법선/높이,
  점프·거미줄 전환, 지지면 소실, 착지 범위 축소, 동적 장애물, 실제 경사·계단, 무입력 정지.
- 기존 컨트롤러·게임플레이 검사, QA 34개 및 2차 검토 11개도 통과했다.
- 브라우저를 최신 코드로 다시 열어 오르막·내리막·계단·옥상 지지/발 올리기/도착 장면을 확인했다.
  경사면과 계단에서 입력을 놓은 뒤 4.9초 장면은 `IDLE`, 속도 0으로 확인했다.
  최종 확인 시 브라우저 오류 목록은 비어 있었다. 최초 일부 캡처는 이전 페이지가 남아 있어
  서버 재시작 및 새로고침 후 다시 촬영했으며 아래 `final` 자료는 최신 캡처다.

## 적용 범위

검증용 경사는 약 16.7도이며 자세 계산에서는 다른 축의 경사도 검사했다.
계단의 단차는 20cm다. 충돌 제어기의 최대 오르기 각도는 45도, 자동 단차 높이는 30cm다.
이 수치를 초과한 지형이나 모든 홍콩 건물·타일 LOD를 실제 플레이로 전수 검증하지는 않았다.
정교한 뒤꿈치→발가락 접촉 역학, 전용 촬영 애니메이션, 모든 모서리/복잡한 장식물에서의
피부 메시 충돌까지 구현하거나 완벽하다고 판정한 것은 아니다.
