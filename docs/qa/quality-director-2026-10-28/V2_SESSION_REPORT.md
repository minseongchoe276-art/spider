## G. 카메라

자동화에서 `#webgl-canvas`는 문서에 연결되어 있고 같은 문서다. `document.hasFocus()`는 true, `navigator.webdriver`는 true였다. `requestPointerLock()`은 evaluate와 실제 pointerdown, 게임의 `계속 플레이` 버튼에서 모두 `WrongDocumentError: The root document of this element is not valid for pointer lock.`을 냈다. `--enable-automation`을 빼도 webdriver는 true로 남고 같은 오류가 났다.

Chromium은 이 문자열을 `PointerLockResult::kWrongDocument`에 붙인다. Playwright macOS 이슈 20956은 자동화 뷰가 포커스된 네이티브 뷰가 아니어서 락이 거절된다고 적는다. 일반 Chrome에서 재현하지 않았으므로 플레이어 입력 버그라고 단정하지 않는다. 상태 UNVERIFIED.

요를 1.4라디안 돌리면 렌더된 시선은 직후 0, 200ms에 1.385, 600ms에 1.4였다. 걷기 중 카메라와 몸 사이 건물 가림은 이번 샘플에서 없었다. 전투 중에는 몸이 카메라를 향해 서므로 카메라를 옆으로 돌려도 등이 보인다. 주먹의 옆모습은 이 방식으로 찍히지 않았다.
