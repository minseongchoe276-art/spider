# 전투 검사

입력은 모두 실제 키와 마우스다. 상대는 없었다. 타격 판정과 피격 연기는 측정하지 않았다.

## 조작 대응

코드 기준:

- 좌클릭: `combat.attack` → 키 `jab`
- 우클릭, 지상 전투: `combat.straight` → 키 `cross`
- E: `combat.heavy` → 키 `heavy`. 안내 문구는 훅. 클립 원천은 Boxing Hook이다.
- G: `combat.special` → 키 `special`. 안내 문구는 돌진 어퍼컷. 기력 35, 재사용 8초.

Q 한 번에 `combat`이 되었고, 다시 Q로 `web`이 되었다.

## 결과

| 시험 | 상태 | 근거 |
| --- | --- | --- |
| 잽 | PASS | `attacks`에 jab |
| 스트레이트 | PASS | cross |
| E | PASS | heavy |
| G | PASS | special |
| 잽 후 560ms 뒤 스트레이트 | PASS | jab과 cross가 같은 기록에 있음 |
| 걷는 중 잽 | PASS | jab |
| 좌클릭 8연타 | PASS | jab이 남고 속력이 유한 |

연타 간격 70ms는 잽 길이 0.72초보다 짧다. 큐는 동작의 75% 이후만 받는다. 연타가 여덟 대의 잽을 모두 시작했는지는 샘플의 키 집합만으로는 알 수 없다. 최소 한 번은 시작했고 값은 터지지 않았다.

기력은 특수기 화면에서 46/100, G 칸에 7초가 보였다. 시작 100에서 잽·스트레이트·훅·어퍼컷 비용과 맞다.

## 눈으로 본 것

하늘로 기울어진 카메라의 잽 화면은 몸이 작고 주먹이 읽히지 않았다. 그 실패는 카메라가 위를 향한 상태였지, 잽 키가 안 나간 상태는 아니었다.

어퍼컷 뒤 화면(`06-special.png`)은 건물 앞의 전투 대기 자세다. 발이 바닥에 있고 건물에 끼지 않았다. 주먹의 중간 궤적 사진은 없다.

모션 리뷰의 훅 45%는 옆으로 휘두르는 훅보다 앞으로 뻗은 주먹에 가까웠다. 한 프레임이다. 클립을 다시 만들지 않았다.

## 하지 않은 것

피격, 가드 경감, 콤보 여섯 종의 타격 타이밍, 타격음, 카메라 흔들림의 크기, 온라인 펀치 동기.

판정: 입력 경로는 PASS. 타격감은 UNVERIFIED.
