# 모션·행동 품질 검수 — 2026-10-13

## 판정

현재 모션·조작 범위에서 재현한 6개 결함을 수정했다. 자동 검사와 브라우저 연결 시나리오를 함께 사용했으며, 단순히 모션 파일이 로딩된다는 것을 정상 동작으로 취급하지 않았다. 실제 33년 경력을 주장하는 보고서가 아니라, 동작의 완결성·전환·물리 접촉·입력 일관성·온라인 표시를 검토하는 전문가 수준의 검수 기준을 적용했다.

## 수정한 결함

| 결함 | 수정과 재검증 |
| --- | --- |
| 모션 전환 중 초기화하면 이전 기술이 계속 혼합됨 | `Character.stopAnimation()`에서 mixer의 모든 action을 중지. 전환 중 초기화 뒤 예약된 action이 0개이며 대기 모션이 다시 재생되는지 실제 리그로 검사했다. |
| 웹 집 도착 때 우클릭만 유지하면 줄을 놓음 | 좌우 버튼 모두 도착 줄을 유지하도록 변경. 유지한 버튼에 줄 소유권을 지정해 같은 버튼을 떼면 해제한다. 양쪽 버튼 각각 검사했다. |
| 상대의 방향별 회피·착지·피격 모션이 전달 과정에서 누락됨 | 원격 pose의 허용 목록에 실제 기술 이름을 추가. 4방향 회피, 내려찍기 착지, 가슴/머리 피격을 검사했다. |
| 상대의 내려찍기 모션이 실제 착지보다 먼저 완료됨 | 원격 시간 보간도 공중에서는 62% 구간에 유지하고 `slamLand` pose를 받은 뒤 착지 모션으로 전환한다. 500ms 지연을 넣어 검사했다. |
| 강한 착지 모션이 다음 프레임에서 일반 착지로 바뀜 | 충격량은 한 프레임 이벤트이므로 LANDING 진입 시 모션을 선택하고 회복 종료까지 유지한다. 수정 전 브라우저 기록의 `slamLand → land → idle`이 수정 후 `slamLand → idle`로 바뀌었다. |
| 예약된 두 번째 주먹은 모션만 재생되고 온라인 타격 요청이 없음 | 클릭 반환값뿐 아니라 실제 공격 action 시작을 관찰하여 요청을 예약한다. 타격 시점에 1회 전달하며, 취소·중복 전달 회귀 검사도 유지했다. |

## 검증 범위와 증거

- `npm test`: 27개 실행 단계. 최종 실행 결과는 [final-tests.log](final-tests.log)에 있다.
- 39개 컴파일 모션 전체 타임라인: 30/60/144 FPS, 117개 경우, 16,183개 프레임. 관절 유한값·정규화·뼈 길이·모션 구간 연속성·공중 내려찍기 대기를 검사했다.
- 39×39 모션 조합: 30/60/144 FPS, 총 4,563개 전환과 107,991개 리그 프레임. 이전 모션의 혼합 잔여, 반복 모션 정지, 초기화 잔여 action을 검사했다. [전환 결과](transitions.json), [전환 검사](../../../scripts/check-motion-transitions.mjs).
- 브라우저에서 12개 동작 연결 시나리오를 실행하고 화면을 저장했다. 이동 속도 전환, 정지, 제자리 회전, 낙하 착지, 구르기, 웹 집, 스윙 해제, 양손 거미줄 교체, 벽→옥상, 경사 오르기/내리기, 계단을 포함한다. [최종 기록](browser-scenarios.json), [착지 수정 전 기록](browser-scenarios-before-landing-fix.json).
- 실제 모델의 39개 모션을 45% 구간에서 렌더링하고 자세 표본을 확인했다. [모션 목록과 시간](browser-clips.json), [전체 자세 표본](motion-contact-sheet.jpg), [원본 화면](screens/).
- 양손 독립 유지/해제, 장애물로 인한 줄 해제, 공중 묘기 6종의 완료/중단/점수, 지상 전투와 공중 거미줄 전환, 착지 회복, 원격 리그의 독립성·오래된 pose 해제를 기존 검사와 함께 재검증했다.
- `npm run build` 성공. 번들 크기 경고는 [build.log](build.log)에 기록했다.

## 판정의 한계

4,563개 전환은 mixer 수준의 전환 조합이다. 모든 조합이 실제 조작으로 가능한 게임 경로라는 뜻은 아니다. 39개 자세 표본도 각 모션의 전체 영상을 육안으로 검수한 결과와 같지 않으며, 공중 이동이 포함된 원본 take 일부는 표본 카메라의 범위를 벗어난다. 전체 구간의 수치 검사는 별도로 수행했다.

실제 브라우저 검수는 로컬 모션 검수 장면과 절차적 도시 기준이다. 홍콩 지형은 자동 충돌·모션 연결 검사 범위에 포함되지만 이번 검수에서 전체 지역의 장시간 수동 플레이를 수행하지 않았다. 원격 모션은 실제 복제 리그 및 전송 pose 검사이며, 수정 후 운영 환경의 두 사용자 경기 전체를 검증한 것은 아니다.

기존 [출시 검증 보고서](../release-audit-2026-10-13/REPORT.md)의 경쟁전 서버 신뢰 및 운영 DB 이동 검증 문제는 이번 모션 수정으로 해결됐다고 간주하지 않는다. 따라서 전체 게임의 무결함이나 경쟁전 출시 승인을 선언하지 않는다. 이번 범위에서 발견한 모션·입력 결함의 수정과 재검증 결과를 기록한다.
