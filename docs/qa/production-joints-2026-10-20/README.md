## 직접 검증하지 못한 부분

- 벽 이동 입력을 시도했지만 실제 등반 상태를 확보하지 못했다. 벽 등반·벽 달리기·난간 기어오르기는 **이번 배포 직접 플레이 통과 항목에 포함하지 않는다**.
- 공중 묘기의 모든 변형, 적의 모든 피격·반격 조합, 멀티플레이 상대 외형은 이번 수동 점검의 전수 검사 대상이 아니다.
- 스크린샷은 입력 후의 표본 프레임이며, 파일 이름의 공격 종류가 정확한 타격 순간을 보증하지 않는다. 일부는 회복·대기 자세이다. `power-contact-hong-kong.png`는 연속 공격 후 화면으로, 강공격 적중 증거로 사용하지 않는다.
