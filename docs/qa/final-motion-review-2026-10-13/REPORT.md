# 실제 브라우저 모션·조준점 최종 재검수

2026-10-13, Codex 내장 Chromium 브라우저, 1280×720, 로컬 개발 서버의 절차적 도시. 코드 주입으로 동작을 만들지 않고 브라우저의 클릭과 키 입력을 사용했다.

- 혼자 플레이 → Space 점프 → T 공중 묘기 → 착지: 묘기 점수 300점, 대기 상태로 복귀했다.
- 착지 후 W 이동: 북쪽 좌표 -175m → -172m. Q 전투 전환 뒤 좌·우 공격 입력을 수행하고 Esc 메뉴로 이동했다.
- 마우스 잠금 없이 계속하기 → W 이동: 북쪽 좌표 -170m. 입력과 이동이 다시 작동했다.
- 시작·착지·전투 전환·메뉴·재개에서 조준점 다섯 표본은 모두 정확히 (640, 360), 28×28px였다. [수치 표본](reticle-samples.json).
- 브라우저 로그의 error/warn 표본은 0개였다. HUD는 약 59~60 FPS, P95 약 18~21ms였다. 이는 해당 짧은 장면의 표시 값이며 전체 지형의 장시간 성능 보장은 아니다.

[최종 화면](gameplay.png), [검수 시점 모션 소스 해시](source.json).

이 기록은 모션 종료 후 이동과 조준점 고정의 실제 UI 증거다. 전체 경쟁전·모든 장시간 플레이·실물 게임패드 검증을 대신하지 않으며 최종 합격은 별도의 전체 검사를 통과해야 한다.
