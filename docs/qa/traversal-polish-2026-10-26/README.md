# 이동 연결 · 기술 HUD · 지도 개선 — 2026-10-26

## 변경

- 스윙·집·벽 이동·점프·낙하·착지·구르기 전환은 직전에 렌더된 보정 자세를 캡처한다. 원본 클립에 없는 손발 접지 결과가 다음 전환의 시작점에서 사라지는 문제를 방지한다. 보행 간 보폭 위상 동기화와 기존 접지·관절 제한은 유지한다.
- 전투 대기는 원본 복싱 클립의 안정된 표본을 사용한다. 움직이지 않을 때 반복되는 발 구름과 접지 IK의 충돌을 제거한다. 명시적인 방어·타격·보행은 각자의 클립 시간을 유지한다.
- Ctrl 회피 입력과 기술 슬롯, 터치 회피 버튼, 키 변경 UI를 제거했다. 게임패드 B는 방어로 연결한다. 기존 회피 데이터/API는 이전 원격 패킷·검사 호환을 위해 남아 있으며 신규 로컬 Ctrl 입력은 해당 API를 호출하지 않는다.
- 하단 기술을 실제 버튼으로 바꾸고 리매핑된 키와 동일한 입력 경로에 연결한다. Q 모드 전환, E 공중 집/지상 훅, G 지상 강공격/공중 내려찍기, B 누르는 동안 방어다. 비용·쿨다운·동작 중 여부·회복 상태·공중 표적 유무를 실제 실행 조건에 맞춘다. 단발 기술은 누를 때 입력을 즉시 해제하여 버튼이 비활성화되어도 키가 남지 않는다.
- 생성형 래스터 이미지로 기술 그림을 교체했다. E는 와이어 모드에서 실크 와이어, 전투 모드에서 주먹 그림을 보여준다. 최종 게임 자산은 `public/images/ability-atlas-v2.jpg`, 제작 원본과 프롬프트는 이 폴더의 `ability-source.png`, `image-prompts.md`다.
- 우측 상단 전체화면·조작 버튼을 아이콘으로 바꾸고 접근성 이름·도움말을 유지했다. 전체화면 상태 동기화가 아이콘을 텍스트로 덮지 않는다.
- 전체 지도 캔버스 최대 크기를 900px에서 520px로 줄였다. 로컬 도시 지도는 도로 중심선·참조 도로명·내 방향·확대 시 내 위치 중심·1/2/4배 축척을 제공한다. 현재 임무 목표는 금색 마름모와 거리, 직선 방향 안내로 표시한다. 이 선은 길찾기 경로가 아니다. 홍콩은 기존 지리 배경과 범위를 유지한다.
