# 전투·거미줄 모드 검증 기록

검증일: 2026-10-11

## 적용 결과

- 기본 전투 모드. Q로 거미줄 모드를 켰을 때만 발사·당기기·웹 집을 허용한다. 모드 전환 시 입력, 방어, 콤보와 거미줄 연결을 정리하고 이동 속도는 유지한다.
- 좌클릭: 왼손 잽 → 오른손 크로스 → 훅의 3타 콤보. 타격 창, 거리, 방향, 높이 및 벽 차폐를 검사하며 한 공격이 같은 대상에 중복 피해를 주지 않는다.
- 우클릭: 전방 방어. E: 지상 강공격 / 공중 내려찍기. 내려찍기 피해는 실제 착지 시 한 번만 발생한다.
- Ctrl+방향: 좌·우·뒤 회피 / 앞 구르기. 기력과 짧은 무적 시간을 적용한다. 거미줄 모드에서는 전투 기술이 실행되지 않는다.
- B: 안전하게 지지되는 바닥에 훈련 드론 최대 3기 소환. 실제 적 캐릭터와 미션 시스템은 이 변경에 포함되지 않는다.
- 전투 모션 14종을 추가했다. 재생 반복 시 같은 모션도 처음부터 재시작하며, 이동 시에는 기존 이동 모션을 사용한다. 펀치의 팔 높이를 보정하고 방어의 하체를 접지된 전투 자세로 재구성했다.
- 시작 화면과 조작 가이드를 모드에 맞게 수정했다. 화면 검사 중 발견한 가이드의 가로 넘침도 수정했다.

## 모션 출처

[Mesh2Motion 공식 저장소](https://github.com/Mesh2Motion/mesh2motion-app)의 human-addon-animations.glb 및 human-base-animations.glb에서 선택한 애니메이션을 다운로드해 사용했다. 저장소의 애니메이션 라이선스는 CC0이며, 로컬 라이선스는 public/models/sources/LICENSE-CC0.md에 보관되어 있다. 소스는 combat-addon.glb와 combat-base.glb에 보관하며, 대상 스파이더맨 뼈대로 변환한 결과는 public/motions에 있다. 방어 자세는 Defend 상체와 Fighting Idle 하체를 조합한 파생 모션이다.

| 게임 동작 | 원본 take |
|---|---|
| 대기 / 잽 / 크로스 | Fighting Idle / Fighting Left Jab / Fighting Right Jab |
| 훅 / 강공격 | Melee_Hook / Punch_Cross |
| 방어 | Defend + Fighting Idle 하체 |
| 좌·우·뒤 회피 / 앞 구르기 | Dodge_left / Dodge_right / Dodge_back / Roll |
| 내려찍기 / 착지 | Attack_Ground_Pound / Land_Three_Point |
| 피격 2종 | Hit_Chest / Hit_Head |

## 검증 결과

- npm test: 전체 기존 검사와 추가 검사 통과.
- 전투 시나리오 9개: 모드 분리, 입력 해제, 콤보, 타격 창과 중복 피해, 차폐·방향·높이, 방어·무적, 방향별 회피, 실제 착지, 안전한 소환 및 자원 해제.
- 실제 캐릭터 자세 42개: 모션 14종 × 30/60/144 FPS. 유한한 관절 값, 정규화된 회전, 접지 및 동일 모션 재시작 검사 통과.
- 거미줄 곡선·섬유 버퍼와 텍스처 파티클 크기·페이드·수명 검사 통과.
- npm run build: 통과. 기존 대형 번들 경고는 남아 있다.
- 브라우저: 실제 게임에서 Q 전환, B 드론 3기 소환, 클릭 공격과 기력 감소 확인. 콘솔 오류 없음. 조작 가이드 배치 확인.
- 별도 combatReview 화면에서 변환된 자세, 실제 콤보 시작 및 공중 내려찍기의 slamLand 전환 확인.
