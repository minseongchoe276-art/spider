# 게임 두 번째 종합 검토 — 2026-10-11

**출시 판단: 상용 출시 보류. 추가 문제 10개를 수정했으며, 홍콩 레이스 가용성과 일부 지도 텍스처 오류는 남아 있다.**

기존 테스트가 모두 통과하는 버전에서도 새로운 결함이 발견됐다. 첫 8개 추가 회귀 시험을 수정 전 백업 소스에 실행했을 때 6개가 실패했고, 해당 원인을 수정한 뒤 통과했다. 최종 `npm test`는 기존 모션·컨트롤러·게임플레이 검사와 QA 34개, 이번 추가 검사 11개를 모두 통과했다. 생산 서버 HTTP 검사 10개, JavaScript 구문 검사 29개도 통과했다. 빌드 성공, `npm audit` 취약점 0건이다.

게임 개발·설계·QA·운영을 함께 보는 숙련 전문가 기준을 적용했다. 실제 44년 경력을 주장하지 않는다. 자동 합성 장면의 성공과 실제 지형에서의 플레이 성공을 구분했다. 이 보고서는 이전 종합 보고서의 최신 상태를 갱신한다.

## 검증 대상과 근거

- 대상: 루트 `spiderman-web-swing`. 하위 `spiderman-game/`는 실행 진입점이 아닌 별도 초기 프로젝트로 변경하지 않았다.
- 환경: macOS, Node 22.19.0, npm 10.9.3, 기존 Codex 인앱 브라우저. 생산 빌드 서버 `http://127.0.0.1:5175/`에서 두 도시를 실행했다. Chrome 제어 스킬의 브라우저 런타임을 사용했다.
- 수정 전 백업: `source-before-review.tar.gz`. 최초 감사와 이번 시작 시점 사이에 소스가 같은 것을 확인했다. 기존 GLB/FBX를 변경하지 않았다.
- 재현 전/후: `evidence/new-regressions-before.log`, `evidence/new-regressions-after.log`. 전 로그는 최초 8개 검사, 후 로그는 확장된 최종 11개 검사다.
- 최종 실행: `evidence/final-test.log`, `final-build.log`, `dependency-audit.json`, `http-smoke.json`, `syntax-check.json`.
- 검증 버전: `evidence/source-manifest.json`의 36개 파일 SHA-256. 실제 로컬 화면, 홍콩 오류, 모션 검증 결과는 같은 evidence 디렉터리에 보존했다.

## 남은 핵심 문제와 후속 검증

**R02 P1 홍콩 레이스 시작 불안정 — 재현됨.** 도시가 준비되어 고도 약20m에서 게임은 시작되지만, R을 누르면 코스 지형/링 공간 부족 알림으로 레이스가 거절됐다. 여러 재로딩에서 재현됐다. 현재 도시는 카메라 주변으로 타일을 요청하고 코스 생성은8개 지점 전체의 바닥·clearance를 즉시 요구한다. 어느 한 지점이 준비되지 않거나 막히면 실패한다. 이번 실행의 정확한 실패 링/후보 원인은 별도로 계측하지 않았으므로 모든 거절을 미로딩 하나로 단정하지 않는다. 코스 영역 미리 로딩, 링 배치 적합성, LOD 변경 후 높이 일관성을 함께 검증해야 한다. 실패를 성공으로 바꾸는 가짜 평면이나 지형 내부 링은 추가하지 않았다.

**R01 P2 홍콩 일부 텍스처 실패 — 재현됨.** `THREE.GLTFLoader: Couldn't load texture blob:...` 오류가 다시 발생했다. 최종 콘솔 JSON에 시각과 번들 URL을 남겼다. 실패 이미지와 원본 tile URL/MIME/바이트 연결이 아직 없어 데이터 손상·지원되지 않는 인코딩·디코더 문제 중 원인은 확정하지 못했다. 3D Tiles 1.1 지원 제한 경고와 텍스처 오류를 인과관계로 단정하지 않았다.

**R03 P2 큰 번들·원본 제작 데이터 포함 — 유지.** 최종 빌드의 메인 JS 약5.25MB/gzip 약1.90MB이며 큰 청크 경고가 있다. 모션 컴파일로 런타임 데이터는 줄었지만 원본 FBX까지 dist에 복사되므로 전체 배포 크기 개선과 동일하지 않다. 별도 청크/지연 로딩과 배포 대상 자산 분리가 필요하다.

**R04 검증 조건 — 실제 완주·장시간·기기 범위 부족.** 합성 8링 완주는 기하 판정/상태/기록 연결 검증이며 실제 조작 난도와 웹 이동 경로 검증이 아니다. 총12분 가상 물리 검사는 렌더링 장시간 안정성 검사가 아니다. 둘을 완료로 섞지 않았다.

**설계 검토 의견 — 확정 버그와 구분.** 첫 로컬 링이 시작점보다 약92m 아래인 경로, 웹 발사 실패 이유 안내, 기본 이동 속도/상승 수단/링 반경의 초보 난도는 실제 플레이테스트로 평가해야 한다. 요구한 재미나 난도가 정해지지 않은 상태에서 수치를 임의 변경하지 않았다. `main`의 입력·상태·UI 결합과 앱 통합 해제 경로 부재는 향후 수정/SPA 삽입 시 위험을 키우므로 구조 개선 후보로 남긴다.

## 결과 해석과 실행

`npm test`의 simulated offline/device unavailable은 의도한 실패 주입이다. 원본 FBX의 TGA/스킨 가중치 경고와 Vite 큰 청크 경고는 테스트 성공과 별도로 남아 있다. 테스트 작성 중 생긴 fixture/구문 오류는 수정 후 최종 전체 테스트를 다시 실행했으며 게임 결함 개수에 포함하지 않았다.

```sh
npm test
npm run build
npm audit
PORT=5175 npm start
node scripts/check-server.mjs http://127.0.0.1:5175/
```

출시 승인 전에는 홍콩 코스 시작과 텍스처 문제를 해결하고, 두 지도 실제8링 완주와 장시간/지원 실기기 검증을 수행해야 한다. 실패·미검증 조건이 남아 있으므로 ‘완벽’, ‘전체 통과’, ‘버그 없음’으로 판정하지 않는다.
