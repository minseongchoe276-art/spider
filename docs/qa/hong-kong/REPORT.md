# 홍콩맵 모션·거미줄 검증

검증일: 2026-10-11. 대상: 현재 로컬 게임, 실제 홍콩 스트리밍 지도 및 동일한 스트리밍 충돌 어댑터. 이 기록은 확인한 조건에 대한 결과이며 모든 장치·지도 좌표의 무결함 보증서는 아니다.

## 수정한 결함

1. **상세도 변경으로 사라진 건물에 거미줄이 계속 붙는 문제**: 렌더링 표면뿐 아니라 현재 완성된 물리 충돌 표면에 앵커가 있는지 검사한다. 스윙·당기기·공중 웹 집에 적용하며, 표면이 없어지면 줄을 해제한다. 해제 시 추가 발사 에너지를 주지 않는다.
2. **새 바닥 충돌이 준비되기 전에 기존 바닥이 사라지는 문제**: 대체 충돌 생성이 진행 중이고 기존 표면이 플레이어를 받치고 있으면 기존 바닥을 유지한다. 생성 후에는 정상적으로 제거한다.
3. **홍콩 건물 텍스처 3개의 로딩 오류**: 실제 실패 원본 `failed-texture.ktx2`를 확보했다. 256바이트 KTX2의 vkFormat 29, 1×1 RGB sRGB 형식이었다. 현재 Three 로더가 직접 읽지 못하는 형식을 RGBA로 변환하고 원래 색상을 보존했다. 표준 glTF 확장의 이미지 로딩 경로에도 적용한다. 수정 후 실제 지도에서 RGB 3개 디코딩, 텍스처 실패 기록 0개를 확인했다.
4. **연결 실패에도 거미줄 충돌 효과가 나오는 문제**: 효과를 실제 연결 성공 콜백에서만 실행한다.
5. **스윙 해제·착지 후 양손 줄이 화면에 남는 문제**: 물리 줄, 양손 표시, 발사 타이머와 포즈 목표를 함께 해제한다. 웹 당기기 착지에도 적용한다. 이후 당기기에 쓸 마지막 앵커 좌표는 별도로 보관한다.

## 실제 홍콩 지도에서 확인한 것

마우스와 키보드로 조작하고 게임이 표시하는 상태 기록과 화면을 저장했다. 검증용 패널은 `hongKongAudit` 쿼리에서만 표시된다.

- 걷기→정지, 질주→정지, 점프→공중 내려찍기→착지: `live-movement.json`.
- 실제 두 건물에 양손 거미줄 연결, SWINGING/swing, 양손 앵커의 물리 표면 지원 true: `swing.json`, `swing.png`.
- F+W와 방향 이동으로 실제 벽 접촉 후 WALL_RUNNING/wall 전환: `live-wall.json`. 이 기록은 벽 진입을 확인하며 홍콩 모든 외벽에서 장시간 오르기와 옥상 진입을 보증하지 않는다.
- 우클릭으로 새 건물에 당기기, WEB_ZIP/zip 전환: `live-pull.json`.
- 최종 빌드에서 양손 스윙과 착지 이후 잔여 줄 제거를 다시 확인했다: `final-swing.json/png`, `final-release.json/png`.
- 실제 홍콩 바닥에서 전투 jab, guard, dodgeBack 전환과 거미줄 모드 분리를 확인했다: `final-combat.json`.
- 최종 빌드 실행 중 해당 번들에서 발생한 콘솔 오류는 확인되지 않았다. 다른 빌드의 과거 오류 기록과 구분했다.

## 자동 검증

`npm test`는 기존 전체 모션·이동·전투·벽·옥상·거미줄 검증과 홍콩 전용 검증을 실행한다. `npm run build`로 실제 서비스하는 dist를 갱신한다. 전체 테스트와 빌드는 통과했다. 출력은 `test.log`, `build.log`에 보관한다.

- 모션 카탈로그 전체 37개, 30/60/144 FPS의 111개 전체 타임라인, 15,219프레임 검사. 실제 전투 리그 42개 경우. 상세 기록: `../motion-audit/REPORT.md`.
- 홍콩 스트리밍 어댑터 8개 경우: 실제 바닥 지원 및 벽 법선, 충돌 준비 전 앵커 거절, 성공 시에만 효과, 당기기 착지 줄 제거, 이동·회피·점프·내려찍기, 사라진 스윙 앵커 해제, 사라진 집 목표 취소, 충돌 교체 중 바닥 유지.
- 텍스처 공통 경로 2개, 실제 홍콩 RGB 데이터 색 보존, 잘린 데이터·지나치게 큰 크기 거절.

어댑터 테스트는 실제 Rapier 충돌과 홍콩 클래스의 지형 API를 사용하되 지형은 재현 가능한 상자·삼각형이다. 실제 홍콩 전체 지도 통과 결과와 혼동하면 안 된다. 보관된 모션 중 일부는 현재 입력에서 호출되지 않는 대체 클립이다.

## 남은 검증 범위

전체 홍콩 좌표의 모든 삼각형·LOD 조합, 모든 카메라 각도에서의 연출, 모바일·게임패드·다른 브라우저와 GPU, 느린 통신·장기 메모리 사용은 이번 결과로 보증할 수 없다. 지도 공급 데이터의 빈 공간과 요철도 존재한다. 현재 빌드에는 대형 번들 경고가 남아 있고 지도 로더에는 3D Tiles 1.1 지원 범위 경고가 있다. 실제 실행 및 수치 검사에서 통과한 조건과 미검증 조건을 분리하여 판단한다.
