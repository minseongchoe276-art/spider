# 모션 연결 구현 기록

기존 검토 보고서의 지적을 바탕으로 이번에는 플레이 로직을 변경했다.

## 플레이에 연결한 요소

- WASD 걷기 1.6m/s, Z+이동 조깅 2.4m/s, X+이동 달리기 4.5m/s, Shift+이동 질주 6.5m/s.
- Walking / Jogging / Running / Fast Run 위상 연결, 재생 속도 동기화. Running은 in-place이므로 측정값이 0에 가까우면 기준 속도 사용.
- 걷기 정지 / 질주 정지, 입력 해제 후 감속 및 완전 정지.
- Q/C 정지 상태 좌우 90도 회전. 원본 골반의 회전과 컨트롤러 방향이 중복 적용되지 않도록 yaw 분리.
- 지상 점프, 느린 낙하의 Jumping Down 공중 구간, 하강 속도 12m/s 초과 자유낙하.
- 실제 충돌 속도 7m/s 초과 착지 회복 / 24m/s 초과 구르기 회복. 공중 구간이 끝난 뒤 착지 구간만 재생.
- 구르기 구간의 골반 수평 이동 거리를 물리 위치에 연결. 회복 중 지면 이탈 시 낙하로 전환하고 기존 벽 충돌 처리 유지.
- 웹 집 WEB_ZIP 독립 상태(0.45초), 점프 기반 자세에 상체 기울임과 발사 손 IK를 추가. 전용 원본 웹 집 모션이 생긴 것은 아님.
- 기존 스윙·좌우 손 IK·줄 해제·슬링샷·공중 회전·벽 달리기·벽 점프·옥상 진입 유지.
- 모션 카탈로그 통합: FBX 18개, 파생 포함 20개 액션. 원본 변형과 Injured Idle은 검증용으로 제공하며 실제 조건이 없는 행동에 억지로 연결하지 않음.
- 검증 화면에 이동 전체 단계, 회전, 중간 낙하, 높은 낙하, 웹 집, 스윙 해제, 벽 달리기 시나리오 추가.

## 검증 범위

`npm test`: 카탈로그 전체 리타게팅, 65개 뼈대 매칭, 유한값/정규화, 루프 경계,
이동 자세 상하 방향, 양손 웹 IK, 제동, 지상 점프, 착지/구르기 상태와 이동 거리,
웹 집 시간, 제자리 회전, 옥상 고속 충돌, 프레임 속도, 카메라 줌 검사.
`npm run build`: 배포 빌드. 원본 FBX 텍스처/스키닝 경고와 번들 크기 경고는 남아 있음.

이번 턴 실제 브라우저 UI 검증은 브라우저 제어 보안 정책에 막혀 완료하지 못했다.
수치 검증 통과는 사람처럼 완전히 자연스럽다는 시각적 판정이 아니다.

## 아직 구현되지 않은 분야

전용 발 고정/지형 IK, 별도 스윙 진입·해제·웹 집 원본 모션, 벽 기어가기·천장 이동,
난간 매달리기·장애물 넘기·전투·피격·체력/부상·사망·상호작용은 완성되지 않았다.
이 분야는 전용 클립과 게임 시스템이 추가로 필요하다. 벽 달리기는 여전히 지상 질주를
벽 방향에 맞춘 파생 표현이고, 묘기는 모델 회전 방식이다.
