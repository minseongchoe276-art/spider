# 홍콩 도시 / 이동 시스템 개선 기록

## 맵 연결

기본 실행 맵은 UrbanGround가 사용하는 홍콩 토지부 3D Tiles이다.
Unity 실행 파일을 변환한 것이 아니라 동일한 공개 도시 데이터를 Three.js에서 읽는다.
건물·인프라·F2 지형을 같은 위도 22.2799955 / 경도 114.165495 기준점으로 변환한다.
건물 JSON 끝의 ECEF 변환 행렬을 무시하고 레이어별로 중심을 옮기던 문제를 수정했다.
F2의 embedded KTX2 이미지에는 KHR_texture_basisu 선언이 없는 경우가 있어 MIME 기반 디코더를 추가했다.
원본 데이터를 모두 다운로드하거나 저장하지 않고 주변을 스트리밍한다.
가시 거리는 1km, 텍스처 포함 타일 캐시는 약 512MiB 예산이다. 로딩 중 초과할 수 있으며 브라우저 전체 메모리 상한은 아니다.
캐시가 가득 차면 세부 수준을 낮추어 가까운 타일 로딩이 막히는 것을 피한다.
파싱 완료 직후가 아니라 좌표 변환 그룹에 활성화된 타일에서 충돌을 생성한다.
시작점은 원점 주변의 걷기 가능한 면과 발 밑 지지 범위를 확인해 선택한다.

## 연결된 게임 시스템

- 120Hz 고정 물리 갱신과 렌더 위치 보간; 30/60/120/144fps 위치 일치 검사.
- 홍콩 타일의 실제 삼각형을 세계 좌표로 변환한 Rapier 캡슐 충돌.
- 30cm 자동 계단, 45도 최대 오르막, 지면 스냅과 상승 중 스냅 해제.
- 점프 예약 140ms, 가장자리 유예 100ms, 포커스 상실 시 입력/조준 해제.
- Space 점프/스윙 해제, E 건물 타깃 웹 집, T 공중 묘기, F 벽 달리기.
- 벽·천장 swept 충돌, 스윙 줄 중간 장애물 검사, 접속 반복으로 속도/공중 능력이 충전되는 문제 방지.
- 착지 충격에 따른 착지/구르기 구분, 회복 중 입력 취소, 실제 지형 기반 접촉시간 예측.
- 실제 지형 높이에 맞춘 대기 발 IK, 웹 집의 손/거미줄 실제 목표점 연결.
- 카메라 중심+주변 탐침이 렌더 메시와 스트리밍 Rapier 충돌 지형을 모두 확인; 보간 위치와 흔들림 결과도 재검사.
- 웹 조준 광선을 눈높이에서 발사하고 카메라 기준 방향으로 조준 보정; 벽 달리기는 실제 파사드 접촉이 끊기면 이탈하고 실제 지붕이 확인될 때만 올라감.
- 지형이 준비된 뒤 시작 허용; 비정상 수치/지형 아래 추락 시 스폰 복구.

## 검증

`npm test`: 기존 FBX 모션/전환 검사, 컨트롤러 검사, 신규 gameplay 검사.
신규 검사는 FPS 독립성, 얇은 벽, 천장, 점프 예약, 스윙 속도 보존, NaN 복구,
실제 삼각형 바닥/벽/계단/경사/천장, 미로딩 공간의 가짜 바닥 부재, 실제 벽·지붕 기반 벽 달리기,
스트리밍 지형 카메라 충돌을 포함한다.
`npm run build`: 배포 번들 생성 검사. 원본 FBX TGA/가중치 경고와 대형 번들 경고는 별도 잔여 항목이다.

## 남은 범위 / 배포 조건

이 작업은 현재의 이동·웹 스윙 게임을 개선한다. 전투, NPC AI, 멀티플레이,
새로운 전용 모션 제작까지 완료한 것으로 표현하지 않는다.
웹 집/벽 달리기/공중 묘기는 기존 클립과 IK/절차 보정이며 전용 원본 모션은 아니다.
이동 중 모든 발의 접촉, 모든 홍콩 소품의 충돌, 모든 네트워크 상황은 완전 검증하지 않았다.
원본 홍콩 데이터에는 스캔 왜곡과 시각적 구멍이 있다. 로컬 충돌은 시각 LOD 전환 중 지지를
보존하기 위해 이전 지형을 최대 약 2초 유지한 뒤 제거한다. 이전 LOD의 가짜 바닥 제거 검사도 추가했다.
LOD끼리 높이가 다른 곳의 모든 전환과 손발 접촉까지 완전 검증한 것은 아니다.
첫 로딩 시간은 원본 서버/인터넷/텍스처 디코딩에 의존하며 오프라인 맵은 아니다.
로컬 실행과 Vite 미리보기는 읽기 전용 프록시를 통해 CORS를 처리한다. 프록시 없는 정적 호스팅은
홍콩 데이터를 불러오지 못한다. 다른 호스팅에 배포하려면 서버 프록시를 연결하고 데이터 이용조건과
출처 표기를 준비해야 한다.
UrbanGround 코드의 라이선스와 홍콩 도시 데이터 이용조건은 동일한 것으로 간주하지 않는다.

## 실행

`npm run dev` → http://localhost:5173/
`?debugCity`는 요청 오류·타일 캐시·카메라 좌표 진단 화면이다.
`?city=procedural`은 비교/회귀 검사용 기존 도시이며 기본 맵은 아니다.
