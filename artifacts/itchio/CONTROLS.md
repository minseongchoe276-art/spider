# SHADOW PULSE 조작표 / Controls

기본 키 기준. Esc 설정에서 변경했다면 게임 내 H 가이드를 우선하세요.

| 입력 | 와이어 모드 / Traversal | 전투 모드 / Combat |
|---|---|---|
| WASD / 방향키 | 카메라 기준 이동 / Move relative to camera | 동일 / Same |
| Shift | 질주 / Sprint | 동일 / Same |
| Space | 점프, 벽 점프, 줄에서 뛰어내리기 / Jump, wall jump, leap off wires | 점프 / Jump |
| 좌클릭 유지 | 왼쪽 버튼의 줄 부착·유지 / Attach and hold one wire | 잽 / Jab |
| 우클릭 유지 | 반대 손 줄 부착·유지 / Attach and hold the other wire | 스트레이트 / Cross |
| 마우스 버튼 놓기 | 해당 줄 해제, 관성 유지 / Release that wire and coast | — |
| E | 공중에서 1회, 최대 12m 집 / One short aerial zip, up to 12m | 지상 훅 / Ground hook |
| F + W | 벽 기어가기·조건 충족 시 옥상 진입 / Climb wall; traverse a safe ledge | — |
| T | 충분한 높이에서 줄을 놓은 뒤 앞구르기 / Front flip after releasing wires with enough clearance | — |
| Q | 전투 모드 전환 / Switch to combat | 와이어 모드 전환 / Switch to wires |
| B 유지 | 온라인 도망자도 방어 가능 / Runners can also block online | 방어 / Block |
| G | — | 강한 스트레이트 / Heavy cross |
| Ctrl + 방향 | 회피 / Dodge | 회피 / Dodge |
| 마우스 이동 | 시점 회전 / Camera | 동일 / Same |
| 마우스 휠 | 줌 / Zoom | 동일 / Same |
| 휠 버튼 드래그 | 마우스 잠금 없이 시점 회전 / Rotate without pointer lock | 동일 / Same |
| C / V | 카메라 정렬 / 3인칭 거리 전환 / Recenter / Cycle camera distance | 동일 / Same |
| Home·End / PgUp·PgDn | 키보드 좌우 / 상하 조준 / Keyboard camera controls | 동일 / Same |
| H / M / Esc | 도움말 / 지도 / 메뉴 / Help / Map / Menu | 동일 / Same |

## 유의사항
- 높은 부착점을 조준하세요. 붙을 표면이 없거나 줄이 가려지면 스윙할 수 없습니다.
- 줄을 놓으면 추가 가속 없이 관성으로 이동합니다. Space는 줄을 놓으면서 도약합니다.
- 현재 공중 묘기는 앞구르기 1종입니다. 방향키 조합으로 다른 묘기가 나오지는 않습니다.
- 경찰과 도망자에서 도망자는 와이어 모드로 고정되고 공격할 수 없습니다.
- 혼자 플레이는 도움말·메뉴에서 정지하지만 온라인 경기는 계속됩니다.
- iframe 저장소 정책 때문에 설정·안전 위치가 유지되지 않는 브라우저도 있습니다.
