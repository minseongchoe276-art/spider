# SHADOW PULSE

로컬 도시는 밝은 낮 조명과 밝은 건물·도로 재질을 사용합니다. 온라인 상대는 위치 공개 주기·준비·탈락 상태와 관계없이 수신한 위치를 미니맵에 표시하며, 연결이 끊기면 마지막 위치를 유지합니다. 미니맵은 기본 320px이고, 상대는 24px 아이콘과 이름·거리로 표시합니다. 지도 범위 밖의 상대는 가장자리 방향표로 안내합니다. 검증 기록: [밝기·상대 위치 개선](docs/qa/visibility-2026-10-14/REPORT.md).

Three.js + Rapier 기반의 키보드/마우스 도시 액션 게임입니다. 에너지 와이어와 근접 전투로 도시를 탐험합니다. 로컬 WebSocket 또는 운영 Supabase 방에서 2~8명이 함께 플레이할 수 있습니다.
기본 지도는 홍콩 3D Tiles 스트리밍이며, 로컬 절차 도시도 제공됩니다.

## 실행

Node.js 22.12 이상을 사용하세요. Supabase SDK는 Node 22 이상을 요구하며, 검증 환경은 Node 22.19.0입니다.

```sh
npm install
npm run dev
```

개발 서버: `http://127.0.0.1:5173/` (포트가 사용 중이면 터미널에 실제 포트가 표시됩니다).
로컬 도시: `http://127.0.0.1:5173/?city=procedural`.

```sh
npm test
npm run build
npm start
```

`npm start`는 `dist`, 실시간 방 서버, 홍콩 지도용 읽기 전용 프록시를 `127.0.0.1:4173`에서 제공합니다.
다른 포트는 `PORT=5175 npm start`로 설정합니다. 온라인 방은 `npm run dev` 또는 `npm start`에서 사용하세요.
같은 네트워크의 다른 기기에서 접속하려면 `HOST=0.0.0.0 npm start`로 실행하고 서버 컴퓨터의 LAN IP와 포트로 접속하세요.
WebSocket 방식의 인터넷 접속에는 이 서버를 공개 호스트에 배포하고 HTTPS/WSS 및 방화벽 설정을 해야 합니다. 이 방식의 방 상태는 서버 메모리에 보관되어 재시작하면 사라집니다. 프로덕션 빌드는 기본적으로 Supabase를 사용하며 운영 설정은 `docs/ONLINE_SUPABASE.md`를 참고하세요.
정적 파일 호스팅만으로는 기본 홍콩 지도 프록시가 제공되지 않습니다. 실제 공개 호스팅에는 이 실행 서버
또는 동등한 `/urban-tiles/api/3d-data/` 프록시와 HTTPS 구성이 필요합니다.
상대 플레이어도 SHADOW PULSE 캐릭터 외형을 사용합니다. 나머지 진행 중인 모션·지도·게임 기능 변경은 이 배포에 포함하지 않았습니다. 운영 Supabase에는 모션 동기화 RPC를 적용하고 실제 2인 접속을 검증했습니다.

### Vercel 화면과 별도 방 서버

Vercel의 정적 배포에서는 기본 Supabase 방 연결을 사용합니다. `/ws` 방식으로 운영하려면 이 저장소의 Node 서버를 WebSocket을 지원하는 별도 웹 서비스에서 실행하세요. Render를 쓴다면 같은 Git 저장소를 연결해 저장소 루트의 `render.yaml` Blueprint로 Web Service를 만드세요. 설정에는 `npm ci && npm run build`, `npm start`, `HOST=0.0.0.0`이 포함되어 있습니다. 호스팅 서비스가 제공하는 `PORT`를 서버가 사용합니다. 무료 플랜은 유휴 시 잠들었다가 다음 연결 때 다시 시작하므로 첫 연결이 늦어질 수 있습니다.

방 서버의 HTTPS 주소가 `https://YOUR-ROOM-SERVER`라면, Vercel 프로젝트의 **Environment Variables**에 `VITE_WS_URL=wss://YOUR-ROOM-SERVER/ws`를 설정하고 **재배포**하세요. 이 값은 브라우저에 포함되는 공개 주소이므로 비밀번호를 넣지 마세요. 로컬 `npm run dev`에서는 이 변수를 설정하지 않으면 기존처럼 같은 주소의 `/ws`에 연결합니다. 로비에 `온라인 · 방을 선택하세요`가 표시되고 실제 방을 만들고 다른 브라우저에서 코드로 입장되는지 확인하세요. 별도 서버를 여러 인스턴스로 늘리면 현재 메모리 기반 방 상태를 공유 저장소로 옮겨야 합니다.

### 독립 게임 서버

`node scripts/room-server.mjs`는 프런트 빌드 없이 `/ws` 게임 서비스와 `/healthz` 상태 확인을 실행합니다. 기본 포트는 4180입니다. `HOST`, `PORT`, 쉼표로 구분한 `GAME_ALLOWED_ORIGINS`로 배포 환경을 지정하세요. 공식 홍콩 지형 캐시를 유지하며, 서버가 역할·수용 위치·피해를 결정합니다. Supabase 비밀 키는 필요하지 않습니다.

공개 호스팅용 무료 설정은 `render-room-server.yaml`에 있습니다. 배포 후 프런트의 `VITE_WS_URL`을 실제 WSS 주소로 설정하고 재배포합니다. 별도 서버의 방은 Supabase 방과 분리되며, 서버 재시작 시 메모리의 방 상태는 사라집니다. [구축·검수 기록](docs/qa/dedicated-room-server-2026-10-13/REPORT.md)을 참고하세요. 공개 호스팅 생성과 실제 인터넷 성능 검수는 Render 계정 연결 후 진행해야 합니다.

## 온라인 플레이

로비의 **혼자 플레이**를 누르면 방이나 서버 연결 없이 자유롭게 도시를 탐험할 수 있습니다. Escape 메뉴에서 로비로 돌아갈 수 있습니다.

로비에서 이름, 방 이름, 정원(2~8명), 모드(경찰과 도망자/자유 플레이)를 선택해 방을 만들 수 있습니다. 열린 방을 클릭하거나 6자리 초대 코드를 입력해 참가합니다. 최소 2명이 모이고 모두 준비하면 방장이 시작합니다.

새 경찰과 도망자 방은 2명 3분, 3~6명 4분, 7~8명 5분 경기입니다. 지형 준비 후 시작하며, 로컬은 반경 300m, 홍콩은 450m 구역에서 진행합니다. 2~6명에서는 경찰 1명, 7~8명에서는 경찰 2명을 무작위로 배정하고, 두 팀은 같은 옥상의 맞은편에서 시작합니다. 시작 후 8초 동안은 공격이 들어가지 않습니다. 경찰만 피해를 줄 수 있습니다. 주먹은 25, 에너지 와이어 발사는 15이며 각 공격은 자기 재사용 시간을 가집니다. 도망자는 에너지 와이어 이동만 할 수 있고 Q로 전투 모드에 들어가지 않습니다. 도망자 전원의 HP가 0이면 경찰이 이기고, 제한 시간이 끝나거나 이동 목표 3개를 완료하면 도망자가 이깁니다. 쓰러진 팀원 곁에서 3초를 유지하면 HP 50으로 구조합니다. 20초마다 3.5초 동안 미니맵에 상대 위치 단서가 공개됩니다. 다음 경기에서는 경찰을 맡은 횟수가 적은 사람이 우선 배정됩니다. 체력이 0인 플레이어는 살아있는 플레이어를 관전하며 화면 버튼으로 대상을 바꿀 수 있습니다. 자유 플레이는 팀/피해/시간 제한 없이 도시를 탐험합니다. H로 화면 가운데 조작 가이드를 열거나 닫습니다.

## 사용자 설정 경기 — 2026-10-20

전용 WebSocket 방 서버에서 **사용자 설정 → 팀전 또는 개인전 → 새 방 만들기**를 선택합니다. 2~8명 정원, 레드·블루 팀 선택, 초대 링크 복사를 지원합니다. 모두 준비한 뒤 방장이 시작합니다. HP 100, 주먹 25 / 거미줄 15, 시작 보호 8초이며 탈락하면 관전합니다. 상대 팀 전원 또는 나머지 개인전 상대가 탈락하면 승리합니다. 팀 변경은 전원 준비를 초기화합니다.

화면 조준 영역·대상 표시와 서버가 같은 거리·높이·방향 기준을 사용하고, 표시한 상대 한 명에게만 공격합니다. 체력 바와 명중·빗나감 사유를 확인할 수 있습니다. 경찰과 도망자에도 같은 기준을 적용합니다. 서버가 새 경기 기능을 지원하는지 확인한 후 방을 생성하므로 이전 서버에서 자유 플레이로 잘못 시작하지 않습니다.

검사: `npm run test:custom`. 공개 배포 검사: `ROOM_SERVER_URL=https://YOUR-ROOM-SERVER node scripts/check-public-custom.mjs`. 이 검사는 임시 방만 생성·정리하며 기존 방을 변경하지 않습니다. [구현·검증 기록](docs/qa/custom-matches-2026-10-20/README.md).

## 조작

- 전투 모드: 좌클릭은 왼손 잽, 우클릭은 오른손 스트레이트. B를 누르는 동안 방어, E는 훅, G는 강한 스트레이트, Ctrl+방향키는 회피. Q로 전투/에너지 와이어 모드를 전환합니다. 경찰과 도망자에서 도망자는 에너지 와이어 모드로 고정됩니다.
- W/A/S/D 또는 방향키: 카메라가 보는 방향이 앞이고 화면 오른쪽이 D입니다. Shift: 질주.
- Space: 점프, 벽 점프. 줄에 매달린 상태에서는 양손 줄을 놓고 위로 뛰어내립니다. 마우스 버튼만 떼면 추가 도약 없이 관성으로 날아갑니다.
- 좌클릭: 꾹 누르면 한 부착점과 고정 길이의 줄에 매달려 진자처럼 스윙합니다. 지상에서 유효한 표면에 처음 부착하면 자동 도약합니다. 상승 중에는 점프 모션을 유지하고 줄에 체중을 싣는 시점에 스윙으로 전환합니다. 높은 부착점을 유지한 채 바닥을 스치면 다시 도약해 스윙을 잇습니다. 누르는 동안 다시 발사하거나 줄을 감지 않습니다. 놓으면 추가 가속 없이 관성으로 날아갑니다. W/A/S/D로 줄의 접선 방향을 조절합니다. 인간 모드에서는 지상 잽을 사용하며 공중에서도 거미줄을 쏘지 않습니다. 거미줄은 Q로 변신한 뒤 사용합니다. 붙을 곳이 없거나 줄 사이가 가려지면 자유 낙하합니다.
- 우클릭: 좌클릭이 쓰는 손의 반대 손에서 같은 진자 스윙을 겁니다. 꾹 누르면 그 줄에 매달리고, 떼면 그 손만 놓으며 추가 가속은 없습니다. 두 버튼을 함께 누르면 두 줄이 같이 몸을 붙잡습니다. 인간 모드에서는 지상 스트레이트를 사용하며 공중 거미줄 발사는 차단됩니다.
- E: 공중에서 한 번 눌러 쓰는 짧은 집입니다. 한 번에 최대 12m이며 꾹 눌러도 자동 반복하지 않습니다. 지상에서는 좌클릭 또는 우클릭을 꾹 눌러 도약 후 스윙으로 출발합니다. 화면 중앙 조준점을 사용하며, 도착 때 좌클릭 또는 우클릭을 누르고 있으면 그 버튼의 줄로 부착점에 매달립니다. 둘 다 누르지 않으면 줄을 놓습니다. 벽에 막히거나 시간이 끝나면 줄을 해제합니다. 지상 전투 모드에서는 훅입니다.
- F+W: 벽 달리기. 공중에서 T: 앞구르기, W+T: 360도 회전, S+T: 뒤구르기, A/D+T: 좌우 옆회전, Shift+T: 코르크스크루. 줄을 놓은 뒤 사용하며 충분한 착지 여유가 필요합니다. 묘기는 동작을 끝낸 후 다시 사용할 수 있습니다. 현재 플레이에는 점수·보상 누적을 연결하지 않습니다.
- F+W를 유지하면 벽 꼭대기의 안전한 옥상으로 손·발 지지를 옮기며 진입합니다. 난간을 넘은 뒤 실제 옥상 바닥에 착지합니다. 진입 공간이 막혔으면 벽을 붙잡고 A/D로 옆의 진입 지점을 찾을 수 있습니다. 진입 중 Space는 점프로 중단합니다.
- C: 카메라 정렬. V: 근접/기본/원거리 3인칭 전환.
- 마우스 휠: 줌. 마우스 잠금 없이 시작하면 휠 버튼 드래그로 카메라 회전.
- Escape: 일시정지/계속. H: 도움말 (Esc 또는 닫기 버튼으로 닫기). 혼자 플레이는 도움말을 읽는 동안 물리가 멈추고, 온라인 경기는 계속 진행됩니다. M: 전체 지도 열기/닫기. H와 M은 키 변경에 사용할 수 없습니다.

일시정지 메뉴에서 시작점 복귀, 효과 줄이기, 그래픽 품질을 설정합니다.
설정, 탐험 구역·이동 거리·와이어 색상과 안전 위치를 브라우저에 저장합니다. 현재 버전에는 레이스·고스트·메달·점수 해제가 없습니다. 와이어 색상은 메뉴에서 선택할 수 있습니다. 브라우저 저장이 차단되면 해당 실행에만 적용됩니다.
진행 기록과 마지막 안전 위치를 저장하고, 동일 지도의 지형 지지와 머리 공간을 다시 확인한 뒤 복귀합니다. 표준 게임패드 조작을 지원합니다. 모바일에서는 높인 플로팅 이동 스틱과 엄지 주변의 원형 동작 버튼을 제공합니다. 점프·집·벽 이동·묘기·회피를 바로 누를 수 있고 동작 버튼을 누른 채 드래그해 조준할 수 있습니다. 전투 모드에는 방어·훅·강공격이 같은 자리에 표시됩니다. [모바일 조작 검증](docs/qa/mobile-ergonomics-2026-10-19/REPORT.md).
로컬 지도는 16개 건물의 작은 도시이며 구역은 ±160m(폭 320m), 홍콩 플레이 구역은 ±2,400m입니다.

## 모션 데이터

`npm run dev`, `npm run build`, `npm test`는 원본 GLB/FBX와 리타게팅 코드의 해시를 확인합니다.
변경된 경우 `public/motions/`에 33개 모션의 트랙 데이터를 다시 생성합니다.
각 트랙 값의 직렬화 전후 일치를 검사하며 원본 FBX는 제작/검증용으로 보존합니다.
컴파일된 트랙을 읽지 못하면 원본 FBX로 복구를 시도합니다.
현재 카탈로그는 24개 원본 경로에서 파생한 33개 클립을 컴파일합니다. 벽 이동과 웹 집은 원본 자세에
런타임 관절 보정을 더하며, 여성 정지 원본은 비교용으로 보존하고 일반 정지에는 사용하지 않습니다.

## 추가된 플레이 기능 — 2026-10-13

현재 버전에서는 레이스·고스트·메달 기능을 제거했습니다. 아래 과거 검증 링크는 당시 구현의 기록이며 현재 기능 목록을 뜻하지 않습니다.

Escape 메뉴에서 카메라 감도·세로 반전·시야각·자동 추적·흔들림·속도 시야각·속도선·HUD 크기를 조절합니다. 조작 키는 중복 배정 시 서로 교환하고, 키 변경은 조작 가이드에도 반영합니다. 에너지 와이어과 질주는 누르기 또는 토글 방식으로 선택합니다. 기본 자동 품질 조절은 지속적인 P95 프레임 지연에 따라 해상도를 조절하며 수동 그래픽 품질을 상한으로 사용합니다.

부착할 지점을 화면 표식으로 안내하고 각 마우스 버튼의 줄 상태와 공중 집 사용 여부를 표시합니다. 부착 실패는 대상·거리·장애물 상태로 안내합니다. 비행 방향 미리 보기는 현재 속도로 줄을 놓았을 때의 짧은 탄도이며 지형을 만나면 멈춥니다. 온라인에서는 부착 보조를 통일하고 비행 미리 보기는 표시하지 않습니다.

현재 버전의 와이어 색상은 기본 흰색·청록·황금·보라 중 선택하며 점수 조건이 없습니다. 이동 속도와 온라인 공격력은 색상에 영향을 받지 않습니다.

전투 연습은 메뉴에서 훈련 표적·근접·원거리·방패·혼합 상대를 선택해 현재 위치 주변의 안전한 바닥에서 시작합니다. 적은 공격을 예고하며, 원거리 투사체는 지형에 막힙니다. 방패에는 훅·강공격을 사용하고, 공중 전투 모드에서 G는 실제 착지에 맞춰 충격 공격을 합니다. 전투 연습은 온라인에서 사용할 수 없습니다. 효과음·환경음·음악 음량을 각각 조절할 수 있습니다.
