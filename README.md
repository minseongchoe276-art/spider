# Spider-Man Web Swing

Three.js + Rapier 기반 데스크톱 키보드/마우스 이동·웹 스윙 게임입니다. WebSocket 방에서 2~8명이 함께 플레이할 수 있습니다.
기본 지도는 홍콩 3D Tiles 스트리밍이며, 로컬 절차 도시도 제공됩니다.

## 실행

Node.js 20.x는 20.19 이상, 22 이상 버전은 22.12 이상을 사용하세요. 검증 환경은 Node 22.19.0입니다.

```sh
npm install
npm run dev
```

개발 서버: `http://127.0.0.1:5173/` (포트가 사용 중이면 터미널에 실제 포트가 표시됩니다).
로컬 도시: `http://127.0.0.1:5173/?city=procedural`.

```sh
npm test
npm run build
npm start
```

`npm start`는 `dist`, 실시간 방 서버, 홍콩 지도용 읽기 전용 프록시를 `127.0.0.1:4173`에서 제공합니다.
다른 포트는 `PORT=5175 npm start`로 설정합니다. 온라인 방은 `npm run dev` 또는 `npm start`에서 사용하세요.
같은 네트워크의 다른 기기에서 접속하려면 `HOST=0.0.0.0 npm start`로 실행하고 서버 컴퓨터의 LAN IP와 포트로 접속하세요.
인터넷 접속에는 이 서버를 공개 호스트에 배포하고 HTTPS/WSS 및 방화벽 설정을 해야 합니다. 방 상태는 서버 메모리에만 보관되어 재시작하면 사라집니다.
정적 파일 호스팅만으로는 기본 홍콩 지도 프록시가 제공되지 않습니다. 실제 공개 호스팅에는 이 실행 서버
또는 동등한 `/urban-tiles/api/3d-data/` 프록시와 HTTPS 구성이 필요합니다.
이 저장소에서 공개 배포는 실행하지 않았습니다.

## 온라인 플레이

로비의 **혼자 플레이**를 누르면 방이나 서버 연결 없이 자유롭게 도시를 탐험하고 타임트라이얼을 즐길 수 있습니다. Escape 메뉴에서 로비로 돌아갈 수 있습니다.

로비에서 이름, 방 이름, 정원(2~8명), 모드(경찰과 도망자/자유 플레이)를 선택해 방을 만들 수 있습니다. 열린 방을 클릭하거나 6자리 초대 코드를 입력해 참가합니다. 최소 2명이 모이고 모두 준비하면 방장이 시작합니다.

경찰과 도망자는 5분 경기입니다. 2~6명에서는 경찰 1명, 7~8명에서는 경찰 2명을 무작위로 배정하고, 두 팀은 같은 옥상의 맞은편에서 시작합니다. 시작 후 8초 동안은 공격이 들어가지 않습니다. 경찰만 피해를 줄 수 있습니다. 주먹은 25, 거미줄 발사는 15이며 각 공격은 자기 재사용 시간을 가집니다. 도망자는 거미줄 이동만 할 수 있고 Q로 전투 모드에 들어가지 않습니다. 도망자 전원의 HP가 0이면 경찰이 이기고, 5분이 끝나거나 경찰이 없으면 도망자가 이깁니다. 체력이 0인 플레이어는 살아있는 플레이어를 관전합니다. 자유 플레이는 팀/피해/시간 제한 없이 도시를 탐험합니다. H로 화면 가운데 조작 가이드를 열거나 닫습니다.

## 조작

- 전투 모드: 좌클릭은 왼손 잽, 우클릭은 오른손 스트레이트. B를 누르는 동안 방어, E는 훅, G는 강한 잽, Ctrl+방향키는 회피. Q로 전투/거미줄 모드를 전환합니다. 경찰과 도망자에서 도망자는 거미줄 모드로 고정됩니다.
- W/A/S/D 또는 방향키: 카메라가 보는 방향이 앞이고 화면 오른쪽이 D입니다. Shift: 질주.
- Space: 점프, 벽 점프. 줄에 매달린 상태에서는 속도를 안고 뛰어내립니다.
- 좌클릭: 누르고 있는 동안 왼손과 오른손 줄을 함께 쓸 수 있습니다. 첫 발사는 왼손, 다음은 오른손이고, 그다음부터는 쏘는 손의 줄만 바뀝니다. 버튼을 떼면 두 줄을 놓으며, 올라가는 중이거나 수평 속도가 빠를 때 속도를 더합니다. 전투 모드여도 공중 좌클릭은 거미줄을 쏘고, 땅에 있을 때만 잽입니다. 붙을 곳이 없으면 그대로 떨어집니다.
- 우클릭: 바라보는 지점으로 집. 조준이 빗나가면 지금 줄이나 마지막 부착점으로 당긴 뒤 한 줄 스윙이 됩니다. E는 공중에서 한 번만 쓰는 강한 집이고, 착지하면 다시 쓸 수 있습니다. 전투 모드에서 땅의 우클릭은 스트레이트, 땅의 E는 훅입니다.
- F+W: 벽 달리기. T: 공중 묘기.
- 벽 꼭대기의 안전한 옥상에는 손·발 지지 전환으로 진입합니다. 진입 중 Space는 점프로 중단합니다.
- C: 카메라 정렬. V: 근접/기본/원거리/1인칭.
- 마우스 휠: 줌. 마우스 잠금 없이 시작하면 휠 버튼 드래그로 카메라 회전.
- R: 타임트라이얼 시작/종료. 금색 링을 순서대로 통과.
- Escape: 일시정지/계속. H: 도움말. M: 음소거.

일시정지 메뉴에서 시작점 복귀, 효과 줄이기, 그래픽 품질을 설정합니다.
설정과 지도별 최고 기록을 브라우저에 저장합니다. 브라우저 저장이 차단되면 해당 실행에만 적용됩니다.
진행 상황/위치 저장, 터치 조작, 게임패드는 구현하지 않았습니다.
로컬 지도 구역은 ±440m, 홍콩 플레이 구역은 ±2,400m입니다.

## 모션 데이터

`npm run dev`, `npm run build`, `npm test`는 원본 GLB/FBX와 리타게팅 코드의 해시를 확인합니다.
변경된 경우 `public/motions/`에 23개 모션의 트랙 데이터를 다시 생성합니다.
각 트랙 값의 직렬화 전후 일치를 검사하며 원본 FBX는 제작/검증용으로 보존합니다.
컴파일된 트랙을 읽지 못하면 원본 FBX로 복구를 시도합니다.
23개는 18개 원본 FBX에서 파생한 클립을 포함합니다. 벽 이동과 웹 집은 원본 자세에
런타임 관절 보정을 더하며, 여성 정지 원본은 비교용으로 보존하고 일반 정지에는 사용하지 않습니다.
`?motionReview`에서 원본 클립과 연결 시나리오를 구분해 볼 수 있고, 시간을 입력해 전환 장면을 재현할 수 있습니다.
경사면에서는 지면 법선 기반 발/골반 보정, 계단에서는 발끝 높이 보정을 적용합니다.
옥상 진입은 캡슐 경로·천장·착지 범위를 검사한 뒤 `MANTLING` 상태로 연결합니다.
